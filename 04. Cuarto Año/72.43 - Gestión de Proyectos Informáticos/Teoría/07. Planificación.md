## Estimación del Costo

El esfuerzo en meses hombre obtenido de *COCOMO* se debe transformar en horas hombre, para que en el plan se utilice la máxima capacidad estimada en la etapa previa. Se utiliza:
$$\text{meses}/\text{hombre}=\text{horas}/\text{mes}\times \text{meses}$$
Podemos tomar el siguiente ejemplo:
1. Estimación de Esfuerzo 23 meses/hombre
2. 23 meses/hombre = 23 meses x 1 persona
3. 1 mes = cantidad días hábiles x horas día
4. 1 mes = 20 días x 8hs = 160 horas
5. 23 meses x 160 horas/mes = 3.680 horas *TOTALES PROYECTO*

El costo global del proyecto se obtiene mediante:
$$\text{Total de Horas del Proyecto}\times \text{Valor de Horas}\times \text{Perfil y Cantidad de Recursos}$$
Esto es una estimación aproximada del costo.

Tomemos el siguiente ejemplo. $\text{Estimación de Esfuerzo} = 3.680\text{hs}$ *TOTALES PROYECTO*. El equipo es de 4 personas:
$$\frac{3680}{4}=920$$
Entonces, 920 horas cada persona.
$$\frac{920}{160}=5.75$$
Entonces, $920\ \text{horas por persona} / 160hs \times \text{mes} = 5,75\  \text{meses}$. El Proyecto tendrá una duración aproximada de 6 meses con 4 recursos. Ahora, hacemos una distribución de las $\text{horas} \times \text{recurso}/\text{perfil} \times \text{valor hora}$. Por ejemplo:
- 3.680 horas TOTALES 
- 920 horas de un Analista 
- Valor hora de analista = $2.000 
- Costo Total Analista = $1.840.000 

Luego, se deben definir la lista de tareas según modelo de proceso (Ej. Proceso de análisis-Educción de requisitos, análisis de usuarios, evaluación heurística, desarrollo, testing funcional), las personas (RRHH) para las diferentes tareas, metodología de trabajo, herramientas de trabajo y necesidades de formación.

>[!TIP] Cprrecta Planificación de Tareas
>Es crítica la correcta planificación de tareas a realizar, recursos, tiempos, entregas. Se deben definir actividades, el modelo de proceso y la metodología de trabajo. La planificación además se realiza al comienzo del proyecto y continúa a lo largo de todo el proyecto con ajustes constantes. Está dirigida a los individuos que participan en un proyecto.

Existen dos enfoques para encarar la planificación del proyecto:
- La fecha final del proyecto se establece a priori.
- Se asumen unos límites cronológicos aproximados, pero la fecha final es fijada por la organización del desarrollo del software.

Luego, se debe plantear una relación gente-trabajo:
- Cantidad adecuada de RRHH
- Conocimiento y perfiles de los RRHH
- Relación entre los integrantes
- Métodos de comunicación de los involucrados
- Estrategias de capacitación

Entonces, las tareas a realizar:
1. Se identifican una serie de tareas del proyecto
2. Se establecen dependencias entre las tareas
3. Se crea una red de tareas
4. Se estima el esfuerzo asociado con cada tarea
5. Se realiza la asignación de personal y recursos
6. Se definen los hitos y entregables
7. Se desarrolla una agenda de fechas

Los métodos de planificación temporal son:
- PERT: técnica de revisión y evaluación de proyecto
- CPM: método del Camino Crítico

Ambos definen una lista de tareas con sus dependencias y restricciones. Las actividades de prueba van arriba en el Trabajo Práctico, porque se hacen antes, no pueden ir abajo.

>[!TIP] Camino Crítico
>Los cálculos de los límites de tiempo llevan a la determinación del **camino crítico**: camino de tareas con holgura cero. Proporcionan al gestor un método cuantitativo para la evaluación del progreso a medida que se van terminando las tareas. Por ende, la planificación temporal proporciona una mirada global para la Gestión del Proyecto.
