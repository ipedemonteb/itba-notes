## Definición

Todo aquello que no tiene solución en los reales, tratamos de entenderlo como que tiene **solución compleja**. Por ejemplo, $x^2+1=0$. Se define la unidad imaginaria $i$ o un número que cumple $i^2=-1 \land (-i)^2=-1$. En general, se tiene $\forall n \in \mathbb{N}$:
- $i^{2n} = (-1)^n$
- $i^{2n+1} = (-1)^n i$

Entonces, un **número complejo** es un objeto matemático de la forma:
$$z = a_z + i b_z, \quad a_z, b_z \in \mathbb{R} \rightarrow \text{forma rectangular}$$
donde a $a_z$ y $b_z$ se las denomina partes real e imaginaria de $z$ respectivamente y se las nota como:
$$a_z = \text{Re}(z) \land b_z = \text{Im}(z)$$

Se define al **conjunto de los números complejos** como:
$$\mathbb{C} = \{a + ib : a, b \in \mathbb{R}\}$$

Una notación común es escribir $\mathbb{C} = \mathbb{R} + i\mathbb{R}$ y de este modo se ve de una manera simple que $\mathbb{R} \subset \mathbb{C}$. Para que tenga sentido el conjunto definido y se pueda trabajar con él, es necesario definir la igualdad y las operaciones que pueden hacerse en él.
Sean $z = a_z + i b_z$ y $w = a_w + i b_w$:
- **Igualdad:** $z = w \iff \text{Re}(z) = \text{Re}(w) \land \text{Im}(z) = \text{Im}(w)$
- **Adición:** $z + w = (\text{Re}(z) + \text{Re}(w)) + i(\text{Im}(z) + \text{Im}(w))$
- **Multiplicación:** $z \cdot w = (\text{Re}(z)\text{Re}(w) - \text{Im}(z)\text{Im}(w)) + i(\text{Re}(z)\text{Im}(w) + \text{Re}(w)\text{Im}(z))$
    - se llega de $zw = (a_z + ib_z)(a_w + ib_w)$ recordando que $i^2 = -1$

## Propiedades

**Propiedades de la Adición**:
1. Ley de Composición Interna: Si $z, w \in \mathbb{C}$ entonces $z + w \in \mathbb{C}$
2. Asociatividad: Si $z, w, u \in \mathbb{C}$ entonces $(z + w) + u = z + (w + u)$
3. Existencia de elemento neutro: $0_{\mathbb{C}} = 0_{\mathbb{R}} + i 0_{\mathbb{R}}$. Se escribirá simplemente 0.
4. Existencia de elemento opuesto: Si $z = a_z + i b_z$ el numero $w = (-a_z) + i (-b_z)$ cumple que $z + w = w + z = 0$. Se escribirá $w = -z$.
5. Conmutatividad: Si $z, w \in \mathbb{C} : z + w = w + z$.

**Propiedades de la Multiplicación**:
1. Ley de Composición Interna: Si $z, w \in \mathbb{C}$ entonces $z.w \in \mathbb{C}$
2. Asociatividad: Si $z, w, u \in \mathbb{C}, (z.w).u = z.(w.u)$
3. Existencia de elemento neutro: $1_{\mathbb{C}} = 1_{\mathbb{R}} + i 0_{\mathbb{R}}$. Se escribirá simplemente 1.
4. Existencia de elemento opuesto: Si $z = a_z + i b_z$ el numero $$w = \frac{a_z}{a_z^2 + b_z^2} + i \frac{-b_z}{a_z^2 + b_z^2}$$cumple que $z.w = w.z = 1$. Se suele escribir $w = z^{-1}$.
5. Conmutatividad: Si $z, w \in \mathbb{C} : z.w = w.z$.

**Propiedad Distributiva**: Si $z, w, u \in \mathbb{C}$ entonces $z.(w + u) = z.w + z.u$.

A partir del hecho de que todo número $w \neq 0$ tiene un inverso multiplicativo, es posible definir la división en $\mathbb{C}$ como:
$$\begin{gathered} \frac{z}{w} = z w^{-1} \quad \text{con } w^{-1} = \frac{a_w}{a_w^2 + b_w^2} + i \frac{-b_w}{a_w^2 + b_w^2} \\[2ex]
\downarrow \\[2ex]
\frac{z}{w} = \left( \frac{a_z a_w}{a_w^2 + b_w^2} + \frac{b_z b_w}{a_w^2 + b_w^2} \right) + i \left( \frac{b_z a_w}{a_w^2 + b_w^2} - \frac{a_z b_w}{a_w^2 + b_w^2} \right) \end{gathered}$$

## Axiomas de Orden

Recordemos los axiomas de orden en $\mathbb{R}$ para luego ver qué ocurre en $\mathbb{C}$. Sean $a,b,c \in \mathbb{R}$, entonces:
- **A.1 Tricotomia:** $a > b \underline{\lor} a = b \underline{\lor} a < b$.
- **A.2 Transitividad:** Si $a < b \land b < c \implies a < c$.
- **A.3 Monotonía I:** Si $a < b \implies a + c < b + c$.
- **A.4 Monotonía II:** Si $a < b \land c > 0 \implies ac < bc$.

En consecuencia:
1. Sean $a, b, c \in \mathbb{R}$. Si $a < b \land c < 0 \implies ac > bc$.
2. Sean $a, b, c \in \mathbb{R}$. Si $a + c < b + c \implies a < b$.
3. Sean $a, b, c \in \mathbb{R}$. Si $a c < b c$ y $c > 0 \implies a < b$.

>[!TIP] Proposición
>No existe un orden en $\mathbb{C}$ que cumpla con los axiomas A.1 a A.4 y sus consecuencias, por lo que suele decirse que $\mathbb{C}$ es un **cuerpo no ordenado**.

## Representación Gráfica y Forma Polar

Si se considera la transformación:
$$T : \mathbb{R}^2 \to \mathbb{C} : T(x,y) = x + iy$$

Es fácil ver que $T$ es un isomorfismo entre espacios vectoriales, por lo tanto se puede decir que $\mathbb{C}$ es isomorfo a $\mathbb{R}^2$ como espacio vectorial. De este modo, es posible pensar a un número complejo como un vector en el plano $\mathbb{R}^2$.
```tikz
\begin{document}
\begin{tikzpicture}[scale=1.5, >=stealth]
  % Ejes
  \draw[->, thick] (-0.3, 0) -- (2.8, 0) node[below] {$x$};
  \draw[->, thick] (0, -0.3) -- (0, 2.2) node[left] {$y$};

  % Coordenadas
  \def\a{1.8}
  \def\b{1.2}

  % Líneas discontinuas de proyección (Verde)
  \draw[dashed, green!60!black, thick] (0, \b) node[left, black] {$b_z$} -- (\a, \b);
  \draw[dashed, green!60!black, thick] (\a, 0) node[below, black] {$a_z$} -- (\a, \b);

  % Vector azul
  \draw[->, blue, thick] (0,0) -- (\a, \b) node[midway, above left, black] {$\rho$};

  % Etiqueta del número complejo
  \node[above right] at (\a, \b) {$z = a_z + i b_z$};

  % Arco del ángulo theta (Rojo)
  \draw[thick, red] (1, 0) arc (0:{atan2(\b,\a)}:1);
  \node[black] at (0.6, 0.25) {$\theta$};
\end{tikzpicture}
\end{document}
```

Donde:
$$\text{fase: } \theta = \text{arctg}\left(\frac{\text{Im}(z)}{\text{Re}(z)}\right)$$

Dado $z = a_z + i b_z$ con $a_z, b_z \in \mathbb{R}$ se define el valor absoluto o módulo de $z$ como:
$$\vert{}z\vert{} = \sqrt{a_z^2 + b_z^2}$$
Es frecuente utilizar la notación $\rho_z = \vert{}z\vert{}$.

Se tienen las siguientes propiedades:
1. $\vert{}z\vert{} \ge 0 \quad \text{y} \quad \vert{}z\vert{} = 0 \iff z = 0$
2. $\vert{}z w\vert{} = \vert{}z\vert{} \vert{}w\vert{} \quad \forall z, w \in \mathbb{C}$
3. $\left\vert{}\frac{z}{w}\right\vert{} = \frac{\vert{}z\vert{}}{\vert{}w\vert{}} \quad \forall z, w \in \mathbb{C}, w \neq 0$
4. $\vert{}z + w\vert{} \le \vert{}z\vert{} + \vert{}w\vert{} \quad \forall z, w \in \mathbb{C}$
5. $\vert{}z - w\vert{} \ge \vert{}\vert{}z\vert{} - \vert{}w\vert{}\vert{} \quad \forall z, w \in \mathbb{C}$
6. $\vert{}\text{Re}(z)\vert{} \le \vert{}z\vert{} \quad \text{y} \quad \vert{}\text{Im}(z)\vert{} \le \vert{}z\vert{} \quad \forall z \in \mathbb{C}$

Definimos el **conjugado** de $z \in \mathbb{C}$ con $z = a + ib$ como:
$$\bar{z} = a - ib$$

Propiedades:
1. $z = \bar{z} \iff \text{Im}(z) = 0$
2. $\overline{z + w} = \bar{z} + \bar{w}$
3. $\overline{zw} = \bar{z} \bar{w}$
4. $\overline{\left(\frac{z}{w}\right)} = \frac{\bar{z}}{\bar{w}}$
5. $z \bar{z} = \vert{}z\vert{}^2$
6. $z + \bar{z} = 2 \text{Re}(z)$
7. $z - \bar{z} = 2 i \text{Im}(z)$
8. $\vert{}z\vert{} = \vert{}\bar{z}\vert{}$

Esto nos sirve por ejemplo para obtener el inverso multiplicativo. Tomemos $z = 2 + i2$:
$$z^{-1} = \frac{1}{z} = \frac{1}{z} \cdot \frac{\bar{z}}{\bar{z}} = \frac{1}{2 + i2} \cdot \frac{2 - i2}{2 - i2} = \frac{2 - i2}{4 - i4 + i4 - (2i)^2} = \frac{2 - 2i}{8} = \frac{1}{4} - i \frac{1}{4}$$

Notemos que en la representación gráfica de este caso tenemos lo siguiente:
```tikz
\begin{document}
\begin{tikzpicture}[scale=1.5, >=stealth]
  % Ejes
  \draw[->, thick] (0,0) -- (2.5,0) node[below] {$\mathrm{Re}$};
  \draw[->, thick] (0,0) -- (0,2) node[above] {$\mathrm{Im}$};

  % Marcas y etiquetas (2)
  \draw[thick] (1.5,0.08) -- (1.5,-0.08) node[below] {$2$};
  \draw[thick] (0.08,1.2) -- (-0.08,1.2) node[left] {$2$};

  % Vector
  \draw[->, thick, teal] (0,0) -- (1.5,1.2);

  % Ángulo theta
  \draw[thick, cyan] (0.5,0) arc (0:38.66:0.5);
  \node[cyan] at (0.7,0.2) {$\theta$};
\end{tikzpicture}
\end{document}
```

Donde:
$$\theta = \text{arctg}\left(\frac{\text{Im}}{\text{Re}}\right) = \text{arctg}\left(\frac{2}{2}\right) = \frac{\pi}{4}$$

Tenemos $\pi/4$, pero también podríamos tener $\theta = \pi/4 + 2\pi$ o $\theta = -7/4 \pi$. Por esto, debemos tomar el argumento principal ($\text{Arg}(z)$), que está entre $0$ y $2\pi$. Tenemos los siguientes casos según el cuadrante:
$$\theta(z) = \begin{cases} 0 & \text{si } b_z = 0 \text{ y } a_z > 0 \\ \text{arctg} \frac{b_z}{a_z} & \text{si } b_z > 0 \text{ y } a_z > 0 \\ \frac{\pi}{2} & \text{si } b_z > 0 \text{ y } a_z = 0 \\ \pi - \text{arctg} \left\vert{} \frac{b_z}{a_z} \right\vert{} & \text{si } b_z > 0 \text{ y } a_z < 0 \\ \pi & \text{si } b_z = 0 \text{ y } a_z < 0 \\ \pi + \text{arctg} \left\vert{} \frac{b_z}{a_z} \right\vert{} & \text{si } b_z < 0 \text{ y } a_z < 0 \\ \frac{3}{2}\pi & \text{si } b_z < 0 \text{ y } a_z = 0 \\ 2\pi - \text{arctg} \left\vert{} \frac{b_z}{a_z} \right\vert{} & \text{si } b_z > 0 \text{ y } a_z > 0 \end{cases}$$

Tenemos las siguientes propiedades:
1. $\text{arg}(z w) = \text{arg}(z) + \text{arg}(w) \quad \forall z, w \in \mathbb{C}$
2. $\text{arg}\left(\frac{z}{w}\right) = \text{arg}(z) - \text{arg}(w) \quad \forall z, w \in \mathbb{C}, w \neq 0$
3. $\text{arg}(z^n) = n \text{arg}(z) \quad \forall z \in \mathbb{C}, n \in \mathbb{N}$
4. $\text{arg}(z^{-1}) = -\text{arg}(z) \quad \forall z \in \mathbb{C} - \{0\}$

La **Fórmula de Euler** nos va a permitir vincular la expresión en coordenadas polares de un número complejo con la forma rectangular.
$$e^{i\theta} = \cos\theta + i \text{sen}\theta \quad \forall \theta \in \mathbb{R}$$

Podemos definir:
- **Forma Polar Elemental:** $z = (\rho, \theta)$
- **Forma Polar Trigonométrica:** $z = \rho \cos\theta + i \rho \text{sen}\theta$
- **Forma Polar Exponencial:** $z = \rho e^{i\theta}$

Sean $z = \rho_z e^{i\theta_z}$ y $w = \rho_w e^{i\theta_w}$, podemos definir:
- **Igualdad:** $$\begin{gathered} z = w \iff \vert{}z\vert{} = \vert{}w\vert{} \land \text{arg}(z) = \text{arg}(w) + 2k\pi, k \in \mathbb{Z} \\[2ex] z = w \iff \rho_z = \rho_w \land \theta_z = \theta_w + 2k\pi, k \in \mathbb{Z} \end{gathered}$$
- **Multiplicación:** $$\begin{gathered} zw = \vert{}z\vert{}\vert{}w\vert{} e^{i(\text{arg}(z) + \text{arg}(w))} \\[2ex] zw = \rho_z \rho_w e^{i(\theta_z + \theta_w)} \end{gathered}$$
- **División:** $$\begin{gathered} \frac{z}{w} = \frac{\vert{}z\vert{}}{\vert{}w\vert{}} e^{i(\text{arg}(z) - \text{arg}(w))} \\[2ex] \frac{z}{w} = \frac{\rho_z}{\rho_w} e^{i(\theta_z - \theta_w)} \end{gathered}$$
- **Potenciación:** $$\begin{gathered} z^n = \vert{}z\vert{}^n e^{i n \text{arg}(z)}, n \in \mathbb{N} \quad \lor \quad z^n = \vert{}z\vert{}^n \cos(n \text{arg}(z)) + i \vert{}z\vert{}^n \text{sen}(n \text{arg}(z)) \\[2ex] z^n = \rho_z^n e^{i n \theta_z} \quad \lor \quad z^n = \rho_z^n \cos n \theta_z + i \rho_z^n \text{sen} n \theta_z \end{gathered}$$
- **Radicación:** Dado $w^n = z$ con $n \in \mathbb{N} \implies w_k = \sqrt[n]{\rho_z} e^{i\left(\frac{\theta_z + 2k\pi}{n}\right)}$ con $k = 0, \dots, n-1$
- **Logaritmación:** Dada $e^w = z \implies$ las sol. son $w_k = \ln(\vert{}z\vert{}) + i(\text{arg}(z) + 2k\pi), k \in \mathbb{Z}$ $$w_0 = \ln(\vert{}z\vert{}) + i \text{arg}(z) \quad \rightarrow \text{valor principal}$$
- **Potencia Compleja:** $z^w = e^{w \ln z}$
