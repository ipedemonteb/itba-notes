## Introducción

**Redis (Remote Directory Service)** es una base de datos clave-valor pensada para ser extremadamente rápido y simple de usar. A diferencia de una base relacional, donde se modelan tablas y joins, en Redis se trabaja con claves y estructuras de datos muy eficientes (cadenas, hashes, listas, conjuntos, etc.) que viven principalmente en RAM. Esta decisión de diseño le permite responder con latencias muy bajas y un throughput alto, lo que lo hace ideal para escenarios donde la velocidad es crítica.
