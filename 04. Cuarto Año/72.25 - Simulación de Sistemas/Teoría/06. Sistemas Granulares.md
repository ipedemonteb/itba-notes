## Definición

Los **medios granulares** son sistemas de partículas del orden macroscópico (granos de arena por ejemplo o incluso polvo). Una de las principales características es que disipan energía al entrar en contacto. Esto se debe a que presentan interacciones a través de fuerzas de contacto normales (deformación viscoelástica) y tangenciales (rozamiento). Tienen características muy particulares que los distinguen de sólidos, líquidos y gases.

Un ejemplo es el flujo granular gravitatorio en silos.

## Propiedades

La **ley de Janssen** establece que en los medios granulares, a diferencia de por ejemplo el agua, la presión dentro del medio granular no depende de la altura de la columna, sino que crece asintóticamente con la profundidad:
$$P(z) \propto \left[ 1 - \exp\left(-\frac{4\mu_p K z}{D}\right) \right]$$
Donde:
* $\mu_p$: coeficiente de fricción con la pared
* $z$: profundidad ($z=0$ es la superficie)
* $D$: Diámetro del contenedor

Otra relación empírica es la **ley de Beverloo**, que establece que el caudal $Q$ constante de un silo se obtiene por análisis dimensional, es decir que se deduce sólo a partir de las unidades físicas de las variables relevantes, sin resolver toda la mecánica granular.
$$Q \approx n_p \sqrt{g} (d - cr)^{2.5} = B (d - cr)^{2.5}$$
Donde:
* $n_p$: Nro. de partículas por unidad de volumen
* $d$: Diámetro apertura de salida
* $r$: radio medio partículas
* $2.5$: Exponente para silo 3D (para 2D es $1.5$)

Cuanto más diámetro, mayor va a ser el caudal, que vemos que sus unidades son cantidad de partículas por unidad de tiempo. El parámetro $c$ es una constante empírica adimensional que corrige el tamaño efectivo del orificio.

## Simulaciones en Medios Granulares

Este tipo de sistemas son densos, es decir que las partículas están en contacto constantemente, por lo que $t_{\text{choque}} \gg t_{\text{vuelo}}$. Se utiliza un método de elemento discreto, la dinámica molecular para granulares. Algunas notaciones utilizadas en el modelo:

|                                Notación                                |                   Concepto                    |
| :--------------------------------------------------------------------: | :-------------------------------------------: |
|                              $\mathbf{g}$                              | Fuerza de Gravedad que apunta en $(-\hat{y})$ |
|              $\dot{\mathbf{r}} = \frac{d\mathbf{r}}{dt}$               |                   Velocidad                   |
|            $\ddot{\mathbf{r}} = \frac{d^2\mathbf{r}}{dt^2}$            |                  Aceleración                  |
| $\dot{\mathbf{r}}_{rel}^c = (\dot{\mathbf{r}}_i - \dot{\mathbf{r}}_j)$ |     Velocidad relativa entre partículas.      |
|          $\xi_{ij} = R_i + R_j -\mathbf{r}_j - \mathbf{r}_i$           |                 Superposición                 |

Podemos definir las siguientes variables geométricas:
![[Pasted image 20260725195846.png|center|279]]

Se considera a las partículas como círculos y se permite que haya superposición entre dos de ellas, como vimos en las notaciones. Es una forma de representar que en la realidad no sucede. En el mundo real se deforman y luego intentan volver a su forma original.

Podemos ahora considerar un límite físico y también vamos a contemplar cierta superposición. La notación es:

|                 Notación                  |                 Concepto                  |
| :---------------------------------------: | :---------------------------------------: |
| $\dot{\mathbf{r}} = (\dot{\mathbf{r}}_i)$ | Velocidad relativa entre partícula pared. |
|     $\xi_{ij} = R_i -\mathbf{r}_{ip}$     |               Superposición               |

Y las variables geométricas:
![[Pasted image 20260725200146.png|center|271]]

Entonces, para hacer las ecuaciones se integran numéricamente las ecuaciones de movimiento acopladas. Las **traslaciones**:
$$m_i\ddot{\mathbf{r}}_i = \sum_{j=\text{vecinas en contacto}} \mathbf{F}_{ij} + \mathbf{F}_g \qquad i=1,...,N$$

Las **rotaciones**:
$$I_i\ddot{\theta}_i = \sum_{j=\text{vecinas en contacto}} \mathbf{M}_{ij}$$
donde $I$ es el momento de inercia y $M$ es el torque definido como:
$$\mathbf{M} = \mathbf{R} \times \mathbf{F}$$

Para partículas circulares, podemos dejar de lado las rotaciones, y el resultado será similar. En este caso, vamos a tener dos direcciones fundamentales, la normal (que apunta desde el centro de masa i hasta el j) y la tangencial, en la cual se van a producir los rozamientos.
![[Pasted image 20260725200446.png|center|277]]
- $\mathbf{\hat{t}}$: versor tangencial al contacto
- $\mathbf{\hat{n}}$: versor normal al contacto
$$\begin{gathered} \mathbf{\hat{n}} = (e_x^n, e_y^n) \\ \mathbf{\hat{t}} = (-e_y^n, e_x^n) \end{gathered}$$
Donde:
$$\begin{gathered} e_x^n = (x_j - x_i)/\vert{}\mathbf{r}_j - \mathbf{r}_i\vert{} \\[2ex] e_y^n = (y_j - y_i)/\vert{}\mathbf{r}_j - \mathbf{r}_i\vert{} \end{gathered}$$

Para las paredes esto es análogo, pero tiene fijas las direcciones tangenciales y normales. No hay que calcularlas todo el tiempo como sí es el caso de las partículas. Se deben tomar versores constantes para cada pared.
![[Pasted image 20260725200539.png|center|224]]
- $\mathbf{\hat{t}}$: versor tangencial la pared
- $\mathbf{\hat{n}}$: versor normal la pared
- $\alpha$ es el ángulo entre el versor normal y el eje x.
$$\begin{gathered} \mathbf{\hat{n}} = (e_x^n, e_y^n) \\ \mathbf{\hat{t}} = (-e_y^n, e_x^n) \end{gathered}$$

La **suma de fuerzas se aplica** de igual manera para las de corto alcance y las de largo, como ya vimos en unidades anteriores. En este sistema funciona bien la idea de Cell Index Method, para ver quiénes están en contacto con quienes.
![[Pasted image 20260724230649.png|center|450]]

Antes de sumar fuerzas, para cada partícula, conviene proyectar las fuerzas normal y tangencial (generadas por cada una de las demás partículas en contacto) en las componentes cartesianas $(x,y)$.
$$\begin{gathered} F_x = F_N \; e_x^n + F_T \; (-e_y^n) \\[2ex] F_y = F_N \; e_y^n + F_T \; (e_x^n) \end{gathered} \qquad \begin{array}{\|l\|} \hline \text{Dado que:} \\ \mathbf{\hat{e}}_n = (e_x^n, e_y^n) \\ \mathbf{\hat{e}}_t = (-e_y^n, e_x^n) \\ \hline \end{array}$$

Vemos que en las fuerzas proyectas en $x$ e $y$ ya está reemplazada la componente $x$ o $y$ de la dirección normal o tangencial, según corresponda. Finalmente la fuerza sobre cada partícula $i$ debido al contacto con las demás partículas, paredes u obstáculos $(j)$ resulta:
$$\mathbf{F}_i^{Tot} = m_i \mathbf{g} + \sum_{j} \mathbf{F}_{Nij} + \sum_{j} \mathbf{F}_{Tij} \quad \Longrightarrow \quad \begin{gathered} F_{i\,x}^{Tot} = \sum_{j} F_{Nij} \, e_{x\,ij}^n + \sum_{j} F_{Tij} \, (-e_{y\,ij}^n) \\ F_{i\,y}^{Tot} = m_i \mathbf{g} + \sum_{j} F_{Nij} \, e_{y\,ij}^n + \sum_{j} F_{Tij} \, e_{x\,ij}^n \end{gathered}$$

Para el elegir el **paso temporal**, se debe considerar el método de integración, pero un ejemplo que podemos tomar como referencia es:
$$\Delta t \approx 0.1 \sqrt{m / k_n}$$

En este caso, a diferencia de la unidad anterior, no vamos a utilizar la conservación de la energía, por lo que tenemos que usar el tercer método de la unidad anterior. Es importante establecer la diferencia entre el paso $\Delta t$ de la simulación y el $\Delta t_2$ para guardar el estado del sistema. Este último:
$$\Delta t_2 = k \, \Delta t, \qquad \text{con } k \in \mathbb{N}$$

Ejemplo:
* $t = \sum \Delta t \quad \text{(El tiempo total)}$

```plaintext
if (t / \Delta t_2) = round (t / \Delta t_2)
    guardo estado sistema.
end
```

## Partículas de Formas Arbitrarias

Para el caso de partículas más complejas, se utiliza el concepto de **esferopolígonos**, que es un método para simular interacciones disipativas y conservativas entre dos cuerpos rígidos con formas complejas en dos dimensiones.

La idea matemáticamente es utilizar una **suma de Minkowski**, que establece que dados dos conjuntos de puntos P y Q en un espacio Euclídeo, esta suma está dada por $P+Q = \{ x+y \mid x \in P,\, y \in Q \}$. Esto es equivalente a arrastrar un conjunto alrededor del perfil del otro.
![[Pasted image 20260725201032.png|center|371]]

La fuerza de interacción entre dos partículas $i$ y $j$ considera los solapamientos entre vértices ($V_i$) de un polígono y lados del otro ($E_j$) y viceversa ($V_j$ y $E_i$):
$$\vec{F}_{ij} = -\vec{F}_{ji} = \sum_{V_i E_j} \vec{F}(V_i, E_j) + \sum_{V_j E_i} \vec{F}(V_j, E_i)$$
