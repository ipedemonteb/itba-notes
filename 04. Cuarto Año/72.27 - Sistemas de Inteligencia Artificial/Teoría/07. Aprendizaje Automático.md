## Aprendizaje

Primero, debemos discutir sobre el concepto de **aprendizaje** y qué es aprender. El pipeline de machine learning contiene problemas que presentan todos el mismo esquema. Primero, tenemos la adquisición de información en forma de señales, que lo podemos pensar como un dataset o matriz, donde las filas son las muestras y las columnas las características. Las tres partes del pipeline son:
- Preprocesado
- Extracción de Características: las características es la unificación de todos los datos conetnidos en una fila. Se identifican patrones específicos que indican lo que el usuario desea realizar.
- Clasificación: Traducen la señal cerebral en una orden lógica o comando digital.

Toda esta información procesada luego se pasa por un sistema de aplicación, que genera un cambio en lo que se está estudiando. Esto genera un feedback para el loop en el que se encuentra todo este proceso.
![[Pasted image 20260712180151.png|center|353]]

El **Problema Inverso en Ingeniería** se define como el desafío de determinar las causas originales de un fenómeno a partir de las observaciones o resultados que este produce. Una señal fuente $s^{L(t)}$ se convierte en una medición $x^{N(t)}$ mediante una función de transferencia $f$ que, inevitablemente, añade un componente de ruido. En términos de ingeniería, esto significa que lo que capturamos con nuestros sensores es una versión distorsionada y ruidosa de la realidad; por lo tanto, el reto principal consiste en modelar matemáticamente esa relación para poder operar sobre ella de manera efectiva. El ruido se va a ir adicionando y en un punto se va a ir de escala. Por esto es que nos sirve tener computadoras digitales, ya que vamos a ir redondeando y evitando este crecimiento. Logramos controlar mejor el ruido.

Con esto en mente, la señal medida atraviesa un Conversor Analógico-Digital (ADC) para transformarse en una secuencia de datos discretos $x^{N[n]}$ que un sistema computacional puede procesar. El corazón de este proceso es el Modelo, el cual tiene la tarea de realizar la "inversión" propiamente dicha: a partir de los datos observados, debe generar una estimación de la fuente original o una salida clasificada. En esencia, mientras que el camino natural va de la fuente a la medición, el problema inverso utiliza la inteligencia artificial y el modelado para recorrer el camino de vuelta, reconstruyendo la información de origen que no es directamente accesible.
![[Pasted image 20260712180352.png|center|429]]

El **aprendizaje automático** se define bajo un enfoque libre de modelo como la capacidad de determinar el mapeo o la relación funcional entre un conjunto de entradas $X$ y sus respectivas salidas $Y$. Este proceso no depende de una estructura teórica rígida previa, sino que se basa en el ajuste de parámetros libres dentro del sistema. El objetivo es que, mediante la observación de datos, el sistema logre configurar estos parámetros de manera que pueda predecir o clasificar correctamente nuevas entradas basándose en patrones identificados previamente. 

Este ajuste de parámetros se lleva a cabo a través de un **proceso de optimización**, el cual busca encontrar la configuración interna que minimice la diferencia entre la salida predicha y la salida real. Al iterar sobre este proceso, el sistema refina sus variables internas de forma automática, permitiendo que el modelo evolucione y mejore su precisión con el tiempo. En esencia, aprender consiste en utilizar algoritmos matemáticos para encontrar los valores óptimos de los parámetros que permiten resolver una tarea específica con el menor margen de error posible.

Como vimos en esta definición, consta en gran parte de un proceso de optimización. Pensemos en el caso de la lata de coca cola. ¿Cuáles deben ser las dimensiones para minimizar la cantidad de aluminio? Tenemos:
- Volumen de un Cilindo: $V=\pi r^2h$
- Área Superficial de un Cilindro: $S = 2\pi r^2 + 2\pi r h$

Recordemos que optimizar siempre es maximizar o minimizar. En este caso, es el segundo proceso para la superficie. Estableciendo que el volumen es 1000 (un litro), se despeja $h$ y se reemplaza:
$$S = 2\pi r^2 + 2\pi r \left( \frac{1000}{\pi r^2} \right) = 2\pi r^2 + \frac{2000}{r}$$
Con esto, se obtiene la derivada y se iguala a cero:
$$\begin{aligned} S' &= 0 \\ 4\pi r - \frac{2000}{r^2} &= 0 \\ 4\pi r &= \frac{2000}{r^2} \\ 4\pi r^3 &= 2000 \\ r^3 &= \frac{500}{\pi} \end{aligned}$$
Luego:
$$r = \left(\frac{500}{\pi}\right)^{1/3}$$
La derivada $S'$ es negativa para $r$ en el intervalo $(0, \left(\frac{500}{\pi}\right)^{1/3})$ y positiva para $r > \left(\frac{500}{\pi}\right)^{1/3}$, por lo que vemos que $r = \left(\frac{500}{\pi}\right)^{1/3}$ es un mínimo. Para este valor de $r$, la ecuación $h = \frac{1000}{\pi r^2}$ nos da $h = \frac{1000}{\pi \left(\frac{500}{\pi}\right)^{1/3}}$.

>[!INFO] Optimización en Aprendizaje Automático
>En todos los casos de aprendizaje automático, se establece una función que tiene que ver con el objetivo y se hace una optimización matemática. Esto permite operar de manera inteligente con los datos.

## Aprendizaje por Datos

El aprendizaje mediante datos en Machine Learning se organiza en tres paradigmas fundamentales, como ya vimos:
- El **aprendizaje supervisado** se basa en el entrenamiento con datos previamente etiquetados por un humano.
- El **aprendizaje no supervisado** busca identificar estructuras o patrones ocultos en los datos sin una guía externa. 
- El **aprendizaje por refuerzo** se centra en que un agente aprenda a tomar decisiones óptimas mediante un sistema de recompensas y penalizaciones basadas en su interacción con un entorno.

Entre los supervisados y no supervisados existen **enfoques híbridos** como el aprendizaje semi-supervisado y el auto-supervisado, que permiten aprovechar grandes volúmenes de datos con etiquetas parciales o generadas automáticamente para mejorar la precisión del modelo.

Todas estas metodologías de aprendizaje se aplican para ejecutar tareas específicas según el objetivo del sistema. Las más comunes son la clasificación, que consiste en asignar etiquetas o categorías a los datos de entrada, y la regresión, orientada a la predicción de valores numéricos continuos. También involucra capacidades más complejas como la generación, donde el modelo crea contenido nuevo (que debe ser indistinguible de los datos originales) basándose en la información aprendida, y la optimización, que busca encontrar la mejor solución posible dentro de un conjunto de restricciones. La efectividad de cada enfoque depende directamente de la calidad de los datos disponibles y de cómo se configure el proceso de ajuste de parámetros para resolver el problema en cuestión.

## Optimización

El problemas básico de la **optimización** es encontrar la combinación de los parámetros para una función que hacen que esta sea lo más grande o más chica posible.
- Minimizar el costo de producción de una empresa.
- Maximizar las ganancias.
- Hallar las medidas del rectángulo que mejor ajusta a la patente en fotos de autos.
- Hallar los parámetros óptimos de una función de distribución para una muestra de datos.

La optimización en ingeniería se clasifica según la naturaleza de las variables y la forma de la función objetivo. La **optimización discreta** se enfoca en problemas donde las soluciones deben ser números enteros o combinaciones específicas, abarcando la programación entera y el estudio de ecuaciones diofánticas. Por otro lado, la **optimización lineal** aborda problemas con relaciones estrictamente proporcionales. En el ámbito de las funciones no lineales, la **optimización convexa** sin restricciones es especialmente valiosa, ya que su estructura matemática permite garantizar matemáticamente el hallazgo de extremos globales, asegurando que el punto mínimo o máximo encontrado sea efectivamente la mejor solución posible para el sistema.

Cuando el modelo presenta una estructura de **optimización no convexa**, la complejidad aumenta debido a la presencia de múltiples óptimos locales que pueden confundir al algoritmo, lo que requiere el uso de diferentes órdenes de métodos para su resolución. Los métodos de primer orden, como el Descenso de Gradiente (GD), su variante estocástica (SGD) y ADAM, utilizan la información de la primera derivada para guiar el ajuste de parámetros. Los métodos de segundo orden, como el de Newton, incorporan información sobre la curvatura de la función para acelerar la convergencia. Finalmente, los métodos de orden cero, entre los que se encuentran la optimización Bayesiana y el método de Powell, operan sin necesidad de calcular gradientes, resultando ideales para escenarios donde la función objetivo es una "caja negra" o no es diferenciable.

Podemos definir entonces genéricamente la **función objetivo**:
$$\begin{gathered} \min_{x \in \Re^n} f(x), \quad f : \Re^n \rightarrow \Re, \quad \vec{x} = [x_1, x_2, ..., x_n] \\ g_i(\vec{x}) \le 0 \\ h_j(\vec{x}) = 0 \end{gathered}$$
Donde:
1. $\vec{x}$ variables de diseño, $f(\vec{x})$ es la función objetivo/costo
2. $g_i$ y $h_j$ son restricciones
3. $\vec{x}^*$ resuelve el problema para $f(\vec{x}^*)$

El **problema general de optimización matemática** consiste en encontrar el conjunto de valores para las variables de diseño, representadas por el vector $\vec{x}$, que minimicen una función objetivo o de costo $f(\vec{x})$. Esta función actúa como el criterio principal para evaluar la calidad de una solución propuesta, transformando un espacio multidimensional de variables en un valor escalar que representa el rendimiento o el error del sistema. El objetivo fundamental es navegar por este espacio de búsqueda para hallar el punto donde el costo sea el menor posible, lo que en el contexto de sistemas inteligentes suele traducirse en la configuración de parámetros que mejor se ajustan a un conjunto de datos o tarea específica.

La **programación lineal** es una técnica de optimización matemática donde tanto la función objetivo como las restricciones que delimitan el sistema son funciones lineales. El proceso busca encontrar los valores de las variables de decisión que maximizan o minimizan un criterio específico, cumpliendo estrictamente con un conjunto de desigualdades que representan limitaciones físicas, técnicas o económicas. El **Método Simplex** es el algoritmo estándar para resolver este tipo de problemas, basándose en la propiedad de que la solución óptima siempre se localiza en los límites del espacio permitido, lo que permite una búsqueda eficiente y estructurada.
![[Pasted image 20260712181543.png|center|310]]

En la **optimización no lineal sin restricciones**, la función objetivo se define como:
$$\min_{x \in \Re^n} f(x), \quad f : \Re^n \rightarrow \Re$$
Donde $f$ es una función no lineal, por ejemplo:
1. $f(x_1, x_2) = x_1^2 + \operatorname{sen}(x_1 * x_2) - x_1 * x_2$
2. $f(x_1, \dots, x_n) = \sum_{i=1}^{n} (x_i - \cos(x_i))^2$
3. $f(x_1, \dots, x_n) = \sum_{i=1}^{n} (x_i - g(x_i, \xi_i))^2$

Nos interesa porque en la optimización de redes neuronales vamos a querer minimizar la función de error:
$$\min_{w \in \Re^n} E(w), \quad E : \Re^n \rightarrow \Re$$
- $E(w_1, \dots, w_n) = \frac{1}{2} \sum_{\mu=1}^{p} \left( \zeta^\mu - g\left( \sum_{i=1}^{n} w_i \xi_i^\mu \right) \right)^2$ es la función de error.
- $w = (w_1, \dots, w_n)$ es el vector de pesos sinápticos que queremos hallar.
- $n$ es la cantidad de pesos sinápticos.

Para resolverlo, tenemos distintos métodos de resolución:
- Métodos exactos: Calculan una fórmula cerrada para la solución.
- Métodos de aproximación de la solución:
	- Métodos basados en las derivadas primeras, o en el gradiente.
	- Métodos basados en las derivadas segundas, o en el hessiano.
	- Métodos sin derivadas.
	- Métodos Estocásticos (estiman la dirección).

Una matriz $A$ es definida como positiva si $\text{x}^TA\text{x}>0,\text{x}≠0$ y todos sus autovalores son positivos. Hay otras características que definen a las matrices definidas positivas, como por ejemplo que los valores de la diagonal deben ser mayores que la suma de los otros elementos de la fila. Si $\text{x}^*A\text{x} ≥ 0, \text{x}≠0$, entonces se dice que la matriz es semidefinida positiva.

Sea la función f diferenciable con primera y segunda derivadas continuas, entonces $x^*$:
- Es mínimo global si $\forall x, \ f(x^*) \le f(x)$
- Es mínimo local si $f(x^*) \le f(x) \ \forall x, \ \Vert{}x - x^*\Vert{} < \epsilon$

Para la optimalidad, se tienen las siguientes condiciones:
- **Condición necesaria de primer orden:** Si $x^*$ es un mínimo local de $f$ entonces $\nabla f(x^*) = 0$.
- **Condición necesaria de segundo orden:** Si $x^*$ es un mínimo local de $f$ entonces $\nabla f(x^*) = 0$ y $H_f(x^*)$ (el hessiano) es una matriz semidefinida positiva.
- **Condición suficiente de segundo orden:** Si $x^*$ es tal que $\nabla f(x^*) = 0$ y $H_f(x^*)$ es definida positiva, entonces es un mínimo local de $f$.

Las **funciones convexas** son aquellas que son diferenciables y donde el punto medio entre dos puntos siempre es menor o igual a la media aritmética entre los dos extremos. Las **funciones cóncavas** se definen de la misma forma tomando el valor inverso de la función.
- Función convexa → Hessiano matriz definida positiva.
- Función cóncava → Hessiano matriz definida negativa.

Las funciones convexas permiten atacar el problema de la optimización con un modelo más simplificado intermedio que ofrece condiciones de optimalidad.

## Procedimiento General de Optimización

El **procedimiento general de optimización** es un proceso iterativo diseñado para aproximarse de manera sucesiva al valor mínimo de una función de costo. El algoritmo comienza en un punto inicial $x_k$ , que actúa como la posición actual en el espacio de búsqueda. A partir de este punto, el sistema debe determinar una dirección de movimiento $d_k$  que apunte hacia una zona de menor costo y calcular una longitud de paso $α_k$, la cual define qué tan grande será el desplazamiento en esa dirección. Esta elección es crítica, ya que una dirección incorrecta o un paso excesivamente largo pueden alejar al sistema del objetivo o causar inestabilidad en la convergencia.

La actualización del sistema se realiza mediante la regla matemática $x_{k+1} = x_k + α_kd_k$, donde el nuevo punto se convierte en la base para la siguiente iteración. Este ciclo se repite hasta que el algoritmo alcanza un criterio de parada, como cuando el cambio entre puntos es despreciable o se llega a un punto donde la pendiente es cercana a cero.

>[!TIP] Elección del Nuevo Punto
>La idea es elegir el nuevo punto de manera que el valor de la función disminuya, o sea que $f(x_{k+1})<f(x_k)$.

Con el algoritmo general, el problema se reduce a:
- Encontrar la dirección de movimiento $d_k$.
- Encontrar el paso adecuado $α_k$.

Se puede establecer:
- Dirección de Decrecimiento: La dirección en la cuál realizar la búsqueda del próximo $x_{k+1}$.
- Condiciones sobre la Dirección de Movimiento: Por supuesto, la idea es que sea descendente, o sea $d_k^t \nabla f(x_k) < 0$.
	- Recordar que el gradiente es la dirección de máximo crecimiento de una función.
	- Cualquier dirección contraria a la del gradiente, es una dirección de decrecimiento de la función.

>[!INFO] Maximización
>Recordemos que en este caso estamos tomando minimización, pero la maximización implica únicamente un cambio de signos.

La **tasa de aprendizaje (o learning rate)** es un parámetro  que determina qué tan grande es el paso que damos en la dirección seleccionada hacia el mínimo.
- Si $\alpha_k$ es demasiado grande: El algoritmo dará pasos gigantes. Esto puede provocar que "salte" por encima del mínimo, oscile de un lado a otro e incluso diverja (se aleje del resultado correcto en lugar de acercarse).
- Si $\alpha_k$ es demasiado pequeño: El algoritmo avanzará de forma extremadamente lenta (como una tortuga). Aunque es muy probable que termine llegando al mínimo, requerirá una enorme cantidad de iteraciones y tiempo de cómputo.

En lugar de usar un valor de $\alpha_k$ fijo y adivinar si es correcto, una estrategia inteligente es calcular el mejor paso posible en cada iteración. Para eso se usa la **búsqueda unidimensional** (o line search). Formalmente, se minimiza el valor de la función $f$ sobre la recta en la que se está haciendo la búsqueda:
$$\alpha_k = \arg\min_{\alpha > 0} g(\alpha) = f(x_k + \alpha d_k)$$

## Métodos de Optimización

El **método del gradiente descendiente**, también conocido como de máximo descenso, es una técnica de optimización de primer orden muy importante en el entrenamiento de modelos de inteligencia artificial. Su principio se basa en una propiedad matemática clave: el gradiente de una función, $\nabla f(x_k)$, señala la dirección de máximo crecimiento en un punto determinado. Por lo tanto, para minimizar una función de costo, el algoritmo debe moverse en el sentido opuesto al gradiente, lo que se define formalmente como la **dirección de búsqueda** $d_k =−\nabla f(x_k)$. Este desplazamiento asegura que, en cada iteración, el sistema baje por la pendiente más pronunciada hacia el valor mínimo.

>[!INFO] Tradeoffs del Método
>Una de las grandes ventajas de este método es su eficiencia computacional y simplicidad, ya que no requiere el uso de segundas derivadas ni el cálculo de matrices complejas como la Hessiana. Sin embargo, esta simplicidad tiene una contrapartida: el método puede presentar una convergencia lenta.

El **método del gradiente descendiente con momentum** surge como una solución técnica para mitigar el problema del zigzagueo u oscilaciones excesivas que presenta el algoritmo estándar en superficies de error con valles estrechos y empinados. Esta técnica introduce un término regularizador que consiste en tomar la dirección de descenso como una combinación lineal entre el gradiente actual y las direcciones calculadas en pasos anteriores. Al incorporar esta "memoria" del movimiento, el sistema logra amortiguar los cambios bruscos de dirección y acelerar la convergencia en el sentido correcto, emulando el comportamiento físico de una bola que adquiere velocidad mientras rueda hacia el fondo de una colina. 
$$x_{k+1} = x_k - \alpha_k \nabla f(x_k) - \beta \alpha_{k-1} \nabla f(x_{k-1})$$
Este promedio ponderado de direcciones no sólo estabiliza el entrenamiento, sino que también permite que el algoritmo atraviese zonas de mesetas o gradientes muy bajos con mayor facilidad, evitando que el proceso de aprendizaje se estanque prematuramente.

El **Método de Newton** es una técnica de optimización de segundo orden que busca el mínimo de una función utilizando no solo la pendiente (gradiente), sino también su curvatura. Aproximamos la función por el polinomio de Taylor de segundo orden,
$$\nabla f(x_{k+1}) = \nabla f(x_k + \alpha_k d_k) = \nabla f(x_k) + \alpha_k H(x_k)d_k$$
Entonces, si $x_{k+1}$ fuera el mínimo, $\nabla f(x_{k+1}) = 0$ y por lo tanto
$$\nabla f(x_k) + \alpha_k H(x_k)d_k = 0$$
de donde resulta
$$d_k = -H^{-1}(x_k)\nabla f(x_k)$$

Los **Métodos Quasi-Newton** surgen como una solución técnica para mitigar el elevado costo computacional que implica el Método de Newton tradicional, específicamente la necesidad de calcular e invertir la matriz Hessiana $H$ en cada iteración. En lugar de realizar este cálculo exacto, estos algoritmos construyen una aproximación de la matriz inversa del Hessiano $H^{-1}(x_k)$ utilizando únicamente la información de los gradientes obtenidos en pasos sucesivos.

El problema fundamental de estos métodos es el alto costo computacional relacionado con la memoria; dado que una red moderna puede tener millones de parámetros, almacenar incluso una aproximación de la matriz Hessiana $B_k$ (una matriz de $N\times N$) se vuelve físicamente imposible en el hardware actual. Por este motivo, los métodos Quasi-Newton estándar no son escalables para modelos de aprendizaje profundo con alta dimensionalidad. Para superar este obstáculo, se recurre al algoritmo **Limited-memory BFGS (L-BFGS)**, que está diseñado específicamente para escenarios con restricciones de memoria. En lugar de intentar construir y guardar la matriz completa, este método implementa una búsqueda iterativa que estima la curvatura del Hessiano basándose únicamente en un pequeño historial de los vectores de gradiente y posición de las últimas iteraciones.

El **Método del Gradiente Conjugado** es un algoritmo iterativo diseñado para encontrar el mínimo de una función objetivo cuadrática o, de forma equivalente, para resolver sistemas de ecuaciones lineales donde la matriz de coeficientes es simétrica y definida positiva. Sea el conjunto de direcciones $d_1, \dots, d_n$ y $A$ una matriz simétrica definida positiva, entonces:
- Si $d_i^t A d_j = 0, \ \forall i \neq j$ entonces se dice que $d_1, \dots, d_n$ son direcciones $A$-conjugadas.
- Si un conjunto de vectores es $A$-conjugado, con $A$ simétrica, definida positiva entonces es también un conjunto linealmente independiente.

>[!TIP] Teorema
>Dada una función cuadrática $f : \Re^n \rightarrow \Re$ $$f(x) = x^t Hx + b^tx$$
>Si un método de minimización no lineal realiza las búsquedas unidimensionales sobre direcciones $H$-conjugadas, entonces el método converge en $n$ pasos.

Existe una variante para este método, que en cada paso $k$ calcula una nueva dirección $d_{k+1}$ que es $H(x_k)$-conjugada con todas las direcciones anteriores $d_1,...,d_k$. Pero para esto hay que conocer el gradiente y el Hessiano.

El **Método de Direcciones Conjugadas de Powell** no necesita derivadas. Funciona muy bien en algunos casos que tengan la forma que vimos en el teorema previo. Este método genera en cada paso $k$ un conjunto de direcciones conjugadas $d_1^k, \dots, d_n^k$.
- Comienza con un conjunto de direcciones l.i $d_1^0, \dots, d_n^0$ y un punto inicial $x_0$.
- En el paso $k$, saca del conjunto la dirección $d_k^k$ y agrega una dirección conjugada con $d_1^{k-1}, \dots, d_{k-1}^{k-1}$ (las de los pasos anteriores).
- La búsqueda lineal es igual que antes.

Algunas observaciones:
- Todos estos métodos fueron desarrollados antes (o al mismo tiempo) de la aparición de Redes Neuronales. 
- Incluso un método que converge en n pasos puede ser demasiado costoso para resolver un problema de redes neuronales.
- Aparece una nueva línea de investigación: desarrollo de métodos de optimización para resolver problemas de Machine Learning

## Funciones de Error

Para transformar un problema de aprendizaje en una tarea de optimización técnica, es fundamental establecer una métrica que cuantifique la discrepancia entre las $p$ observaciones de entrenamiento y nuestra función aproximada $g(\cdot)$, definiendo así el error acumulado que el algoritmo deberá minimizar.

Supongamos que tenemos un problema de aprendizaje supervisado, donde queremos aprender una función $f(\xi) = \zeta$, donde tenemos $p$ observaciones $\xi^\mu = \{\xi_1, \dots, \xi_n\}, \mu = 1, \dots, p$ de dimensión $n$ del conjunto de entrenamiento $(\xi)$ junto con sus $p$ salidas $\zeta^\mu$ de dimensión 1. Queremos encontrar una función $g(\cdot)$ que aproxime $f(\cdot)$ lo mejor posible. Para eso podemos plantear
$$E(\cdot) = \frac{1}{2} \sum_{\mu=1}^{p} (\zeta^\mu - g(\xi_i^\mu))$$

Si hacemos que $g(\cdot)$ dependa de parámetros libres, que vamos a llamar $w = (w_1,...,w_n)$, lo que podemos hacer es plantear esto como un problema de optimización e intentar buscar los $w$ que minimizan y así encontrar $w^*$ con alguna formulación para $g$, como por ejemplo combinación lineal:
$$g(\xi_i^\mu) = \sum_{i=1}^{n} w_i \xi_i^\mu$$

Así, definimos una función de costos clásica de redes neuronales, que es la que vamos a buscar optimizar:
$$E(\mathbf{w}) = \frac{1}{2} \sum_{\mu=1}^{p} (\zeta^\mu - \sum_{i=1}^{n} w_i \xi_i^\mu)$$

Así el problema de aproximar $f$ con $g$ se reduce a optimizar $g$ en base a los parámetros libres $w$ de forma que se minimice $E(w)$.

Entonces, aparecen lo que se llaman **métodos estocásticos**, que están orientados a funciones de error. La idea es que, como la función es muy larga y muy compleja (ya que va muestra a muestra), hace una especie de estimación, como la media de todos los valores.
$$E(\mathbf{w}) = \frac{1}{p} \sum_{\mu=1}^{p} E^\mu(\zeta^\mu, \xi^\mu, \mathbf{w})$$
Es decir, a la función a optimizar la podemos visualizar con el cálculo de un estimador del comportamiento poblacional de los patrones.

El **Gradiente Descendiente Estocástico** es uno de estos métodos. En términos matemáticos, el estimador del gradiente es el promedio de los gradientes individuales de cada observación del conjunto de entrenamiento, lo cual representa la dirección ideal para reducir el error total. $\frac{1}{p} \sum_{\mu=1}^{p} \nabla_w E(\xi^\mu, \mathbf{w}^t)$ es un estimador de la esperanza del gradiente, dado un conjunto de entrenamiento.

Una solución computacionalmente adecuada, es obtener $\nabla_w E(\xi^\nu, \mathbf{w}^t)$ para algún subconjunto $\nu$ arbitrario de los patrones (en vez de elegirlos a todos). Así surgen los **minibatch**, que son un subconjunto aleatorio $\sum_{\mu=1}^{k} \nabla_w E(\xi^\mu, \mathbf{w}^t), \ k \ll p$.

>[!INFO] Diferencia con el Método de Gradiente Descendiente
>La diferencia con el método de gradiente descendiente es que en el Estocástico, solamente una parte de los datos se utiliza para calcular la dirección de descenso en cada paso.
