## Introducción

Una **red neuronal** es un tipo de algoritmo de aprendizaje automático que está modelado según la estructura y función del cerebro humano. Consiste en una gran cantidad de nodos de procesamiento interconectados (neuronas) que trabajan juntos para procesar y analizar datos. Cada neurona recibe uno o más inputs, los procesa utilizando un conjunto de pesos aprendidos y produce y una salida que se transmite a otras neuronas en la red. 
![[Pasted image 20260712185732.png|center]]

El aprendizaje supervisado entrena un modelo con datos etiquetados, es decir cada ejemplo de entrada tiene una respuesta correcta conocida, para que aprenda a predecir esa respuesta en datos nuevos (por ejemplo, clasificar emails como spam o no spam). El aprendizaje no supervisado, en cambio, trabaja con datos sin etiquetas y el modelo debe encontrar por sí solo patrones, estructuras o agrupaciones ocultas en los datos (por ejemplo, agrupar clientes por comportamiento de compra sin saber de antemano qué grupos existen). En resumen:
- supervisado = aprender con guía
- no supervisado = explorar sin guía.

## Perceptrón

El modelo del **perceptrón** se inspira en las neuronas del mundo real, que podemos observar en la siguiente imagen. Las conexiones traseras que se conectan con otras neuronas se llaman dendritas. En el cuerpo se realiza un procesamiento, y en caso de ser necesario se envía un estímulo a partir del axón. La parte de sinapsis es un espacio entre la conexión de dos neuronas que indica la fuerza de esa conexión, y dice que tanto el impulso logra llegar a la otra neurona. 
![[Pasted image 20260712185840.png|center|508]]

Visto ahora desde el modelo computacional:
![[Pasted image 20260712185941.png|center|311]]

La **función de activación** va a determinar si se dispara el estímulo o no, evaluando la suma ponderada de las entradas de la neurona y transformándola en una salida (generalmente entre 0 y 1, como el siguiente caso, o entre -1 y 1) que indica el grado de activación.
$$\begin{aligned} O &= \theta\left(\sum_{i=1}^{n} x_i w_i - u\right) \\[2ex] \theta(x) &= \begin{cases} 1 & x \ge 0 \\ 0 & \text{en otro caso} \end{cases} \end{aligned}$$

## Hiperplano de Separación

Tomemos el caso de que, según algunos parámetros, queremos saber quién va a ganar una elección. Armamos la siguiente tabla con encuestas:
![[Pasted image 20260712190302.png|center|324]]

Si graficamos esto, notemos que podemos trazar una recta que divida todo en dos grupos, y clasificar para edad e ingreso a qué partido votará.
![[Pasted image 20260712190412.png|center|314]]
Es una recta, pero podría ser también un plano en el caso de tener 3 dimensiones. La proyección de un punto sobre el hiperplano, correspondiente a la recta que pasa por el origen:
$$\text{proyección}=\sum^2_{i=1}x_i\cdot w_i$$
Si la proyección es negativa, la clase del dato será (-1), mientras que si es positiva la clase será (1). La recta se representa mediante $y=\frac{1}{2}x$, pero podemos reescribirla como:
$$\begin{aligned} y - \frac{1}{2}x + 0 &= 0 \\ w_2 - \frac{1}{2}w_1 + w_0 &= 0, \ w_0 = 0\end{aligned} $$
Y tenemos algo que se parece más a lo que vimos antes. Entonces:
$$\begin{aligned} \text{clase} &= \theta\left(\sum_{i=1}^{n} x_i w_i\right) \quad n = 2 \\[2ex] \theta(x) &= \begin{cases} 1 & x \ge 0 \\ -1 & \text{en otro caso} \end{cases} \end{aligned}$$

Pero tomemos el siguiente caso:
![[Pasted image 20260712190832.png|center|321]]
Hacemos lo mismo:
$$\begin{gathered} ax + by + c = 0 \\[2ex] w_1 x_1 + w_2 x_2 + w_0 = 0 \\[2ex] \sum_{i=1}^{n} x_i w_i + w_0 = 0 \end{gathered}$$
Generalizamos:
$$\begin{aligned} \text{clase} &= \theta\left(\sum_{i=1}^{n} x_i w_i + w_0\right) \\[2ex] \theta(x) &= \begin{cases} 1 & x \ge 0 \\ -1 & \text{en otro caso} \end{cases} \end{aligned} $$
Y así llegamos a la generalización:
$$O=\theta(\sum^n_{i=1}x_i\cdot w_i-u)$$

Ahora, veamos que cada vez que la neurona recibe un estímulo, los pesos sinápticos
pueden actualizarse (proceso iterativo):
$$w^{\text{nuevo}}=w^{\text{anterior}}+\Delta w$$
Para calcular el delta:
$$\Delta w = \begin{cases} 2\eta x^{\mu}\zeta^{\mu} & O^{\mu} \neq \zeta^{\mu} \\ 0 & \text{en otro caso} \end{cases}$$
Donde:
- $\eta$: tasa de aprendizaje (escalar)
- $x^{\mu}$: entrada o dato
- $\zeta^{\mu}$: salida esperada
- $O^{\mu}$: salida obtenida

Si consideramos que la salida puede ser 1 o -1, como en el caso de elección de un partido u otro, podemos reformular: 
$$\Delta w = \eta(\zeta^{\mu} - O^{\mu})x^{\mu}$$
Donde la salida de la neurona está representada por:
$$O(x) = \sum_{i=1}^{n} x_i \cdot w_i + w_0$$
Entonces, el algoritmo de entrenamiento del perceptrón simple es:
```Plaintext
Initialize weights w to small random values
Set learning rate η

for a fixed number of epochs:
    For each training example μ in the dataset:
        1. Calculate the weighted sum:
           h^μ = w₀ * x^μ₀ + w₁ * x^μ₁ + w₂ * x^μ₂ + ... + wₙ * x^μₙ

        2. Compute activation given by θ:
           O(h^μ) = θ(h^μ) = 1 if h^μ > 0 else 0

        3. Update the weights and bias:
           For each weight wᵢ:
               wᵢ = wᵢ + η * (y - output) * x^μᵢ

        4. Calculate perceptron error:
           error = f(x^μ₁, x^μ₂, ..., x^μₙ)
           convergence = True if error < ε else False
           if convergence: break

End
```

Existen distintas formas de calcularlo para evaluar la convergencia en el fragmento `error = f(...)`:
- La suma del valor absoluto de los errores devuelve cero: Significa que el modelo ya no comete fallos en ningún ejemplo de entrenamiento.
- Accuracy es del 100%: Esto aplica específicamente para problemas de clasificación, indicando que todas las predicciones son correctas.
- ... (otras métricas según el caso)

## Aprendizaje y Generalización

Lo que hicimos hasta ahora es **aprendizaje**. Refiere al proceso de entrenar un perceptrón sobre un conjunto de datos, con el objetivo de minimizar el error o la función de costo de la red sobre las entradas del conjunto de datos. La **generalización** refiere a la habilidad del perceptrón de desempeñarse correctamente sobre datos que no fueron alimentados durante el entrenamiento.

>[!TIP] Garbage In Garbage Out
>Es importante tener en cuenta el concepto de **garbage in garbage out**. Significa que si los datos de entrenamiento son de mala calidad, están mal etiquetados o son poco representativos, el modelo aprenderá patrones incorrectos y producirá predicciones igualmente malas, no importa qué tan sofisticada sea la arquitectura de la red.

## Perceptrón Simple Lineal

Tomemos ahora el siguiente caso, donde ya no queremos separar los datos, sino ajustar la recta que pase más cerca de ellos. Es decir, necesitamos encontrar los valores de $w$ que me permitan encontrar un hiperplano que ajuste lo mejor posible al conjunto de datos.
![[Pasted image 20260712192638.png|center|462]]

En **Adaptive Linear Element (ADALINE)** cambiamos la función de activación por la identidad:
$$
\begin{array}{c}
O(h) = \theta(h(x)) = \displaystyle\sum_{i=1}^{n} x_i \cdot w_i + w_0 \\
\downarrow \\
\theta(h) = h
\end{array}
$$

La salida del perceptrón ya no está confinada a ser binaria: toma valores en los reales. Entonces, ahora debemos considerar cómo calculamos el $\Delta w$. Contemplemos lo siguiente:
![[Pasted image 20260712192952.png|center|545]]

Podemos usar la siguiente función de error:
$$E(O) = \frac{1}{2} \sum_{\mu=0}^{p-1} (\zeta^{\mu} - O^{\mu})^2$$
La salida del perceptrón depende, a su vez, de los pesos sinápticos.
$$E(w) = \frac{1}{2} \sum_{\mu=0}^{p-1} \left( \zeta^{\mu} - \theta \left( \sum_{i=0}^{n} x_i^{\mu} \cdot w_i \right) \right)^2$$
Como la sumatoria comienza en cero, se está contemplando el umbral (bias). Para ver el $\Delta w$, vamos a minimizar esta función usando lo que vimos en optimización.
$$\Delta w = -\eta \frac{\partial E}{\partial w}$$

Podemos verlo gráficamente para 3 parámetros. Vamos a querer encontrar los mínimos de toda esa función que expresa el error $E$.
![[Pasted image 20260712193302.png|center|415]]

El desarrollo de $\frac{\partial E}{\partial w}$ nos queda:
$$
\begin{aligned}
\frac{\partial E}{\partial w_i} = \frac{\partial \left( \frac{1}{2} \displaystyle\sum_{\mu=0}^{p-1} \left( \zeta^{\mu} - \theta \left( \sum_{i=0}^{n} x_i^{\mu} \cdot w_i \right) \right)^2 \right)}{\partial w_i} &= \sum_{\mu=0}^{p-1} \left( \left( \zeta^{\mu} - \theta \left( \sum_{i=0}^{n} x_i^{\mu} \cdot w_i \right) \right) (-1) \theta' \left( \sum_{i=0}^{n} x_i^{\mu} \cdot w_i \right) x_i^{\mu} \right) \\[2ex]
&= \sum_{\mu=0}^{p-1} (\zeta^{\mu} - O^{\mu}) (-1) \theta'(h^{\mu}) x_i^{\mu} = - \sum_{\mu=0}^{p-1} (\zeta^{\mu} - O^{\mu}) \theta'(h^{\mu}) x_i^{\mu}
\end{aligned}
$$
Entonces, la fórmula de actualización de los pesos al evaluar un dato de entrada:
$$\Delta w = -\eta \frac{\partial E}{\partial w} = \eta(\zeta^{\mu} - O^{\mu})\theta'(h)x^{\mu}$$
Y notemos que no depende de la función theta, sino que puede ser cualquiera siempre y cuando sea derivable.

El algoritmo para la perceptrón lineal es igual al anterior:
```Plaintext
Initialize weights w to small random values
Set learning rate η

for a fixed number of epochs:
    For each training example μ in the dataset:
        1. Calculate the weighted sum:
           h^μ = w₀ * x^μ₀ + w₁ * x^μ₁ + w₂ * x^μ₂ + ... + wₙ * x^μₙ

        2. Compute activation given by θ:
           O(h^μ) = θ(h^μ) = h^μ

        3. Update the weights and bias:
           For each weight wᵢ:
               wᵢ = wᵢ + η * (y - output) * θ'(h^μ) * x^μᵢ

        4. Calculate perceptron error:
           error = f(x^μ₁, x^μ₂, ..., x^μₙ)
           convergence = True if error < ε else False
           if convergence: break

End
```

Para la implementación, conviene construirse un conjunto de datos que sean puntos pertenecientes a una recta y ajustarlos. El tipo de entrenamiento, tanto del algoritmo anterior como de este algoritmo, corresponde al formato **online** (lo veremos más adelante).

## Perceptrón Simple No Lineal

Antes tomemos el caso en que no tenemos una recta que ajuste los datos, sino una función no lineal.
![[Pasted image 20260712194030.png|center|486]]

Lo que hacemos, es cambiar la función de activación por una sigmoidea, tanh o logística:
$$
O = \theta\left( \sum_{i=0}^{n} x_i \cdot w_i \right) \qquad \begin{array}{ll} \theta(x) = \tanh(\beta x) & Im = (-1, 1) \\ \theta(x) = \frac{1}{1+\exp^{-2\beta x}} & Im = (0, 1) \end{array}
$$
La fórmula de error se mantiene igual al perceptrón lineal:
$$E(O) = \frac{1}{2} \sum_{\mu=0}^{p-1} (\zeta^{\mu} - O^{\mu})^2$$
La fórmula de actualización de los pesos al evaluar un dato de entrada es, al igual que antes:
$$
\begin{matrix}
w^{nuevo} = w^{anterior} + \Delta w \\
\Delta w = -\eta \frac{\partial E}{\partial w} = \eta \displaystyle\sum_{\mu=0}^{p-1} (\zeta^{\mu} - O^{\mu}) \theta'(h) x^{\mu}
\end{matrix}
$$
Es muy importante la salida de la neurona, porque tomemos las salidas de estas nuevas funciones:
$$
\begin{matrix}
\theta(h) = \tanh(\beta h) \\
Im = (-1, 1) \\
\theta'(h) = \beta(1 - \theta^2(h))
\end{matrix}
\qquad\qquad\qquad
\begin{matrix}
\theta(h) = \frac{1}{1+\exp^{-2\beta h}} \\
Im = (0, 1) \\
\theta'(h) = 2\beta\theta(h)(1 - \theta(h))
\end{matrix}
$$
Vemos que la imagen cae en $(-1, 1)$ para $\text{tanh}$ y $(0, 1)$ para la función logística. Entonces, si queremos calcular un salario vamos a tener que realizar una normalización.

En el caso de la tangente hiperbólica, el parámetro beta que cambia la forma:
$$
\begin{matrix}
\theta(h) = \tanh(\beta h) \\
\theta'(h) = \beta(1 - \theta^2(h))
\end{matrix}
$$
En el caso de la función logística, sucede lo mismo:
$$
\begin{matrix}
\theta(h) = \frac{1}{1+\exp^{-2\beta h}} \\
\theta'(h) = 2\beta\theta(h)(1 - \theta(h))
\end{matrix}
$$

Los perceptrones se pueden combinar como queramos. Pensemos ahora, ¿qué problemas puedo representar? El **Teorema de Aproximación Universal** establece que una red neuronal con al menos una capa oculta, que contenga un número finito de neuronas y funciones de activación no lineales (como *sigmoide* o *ReLU*), puede aproximar cualquier función continua con alta precisión. Lo importante es que existen muchas flexibilidades para armar este modelo, pero nunca se establece si se va a encontrar la solución ni si se puede armar (nunca se indica la cantidad de neuronas).

Entonces, un **perceptrón multicapa** tiene las siguientes conexiones entre las capas, comenzando por la cero y llegando a la de salida. Queremos más de una neurona en esta última capa para, por ejemplo, clasificar en varios grupos. Además, no nos interesa solamente saber si es una u otra clase, sino también el grado de probabilidad de que realmente pertenezca a ella.
![[Pasted image 20260712195023.png|center|570]]

Pero todo este tiempo notemos en los esquemas que estuvimos recalculando con regla de la cadena a medida que nos movimos por las capas. Para programar esto de una manera eficiente, se usa lo que se conoce como **backpropagation**. Es el algoritmo fundamental que permite a las redes neuronales aprender. Técnicamente, es un método para calcular el gradiente de la función de error con respecto a todos los pesos de la red de manera eficiente. Es una aplicación práctica de la Regla de la Cadena del cálculo, que permite "repartir la culpa" del error final entre todas las neuronas de las capas anteriores. Lo podemos ver:
$$\begin{matrix} 
\frac{\partial E}{\partial W_{11}} = \bbox[border:2px solid red]{\frac{\partial E}{\partial O_1} \frac{\partial O_1}{\partial h_1}} \frac{\partial h_1}{\partial W_{11}} \\ \\ 
\frac{\partial E}{\partial w_{11}^2} = \bbox[border:2px solid red]{\frac{\partial E}{\partial O_1} \frac{\partial O_1}{\partial h_1} \frac{\partial h_1}{\partial V_1^2} \frac{\partial V_1^2}{\partial h_1^2}} \frac{\partial h_1^2}{\partial w_{11}^2} \\ \\ 
\frac{\partial E}{\partial w_{11}^1} = \bbox[border:2px solid red]{\frac{\partial E}{\partial O_1} \frac{\partial O_1}{\partial h_1} \frac{\partial h_1}{\partial V_1^2} \frac{\partial V_1^2}{\partial h_1^2} \frac{\partial h_1^2}{\partial V_1^2} \frac{\partial V_1^2}{\partial h_1^1}} \frac{\partial h_1^1}{\partial w_{11}^1} 
\end{matrix}$$

Es importante porque permite resolver el problema de determinar cuánto contribuye cada neurona al error del perceptrón multicapa de manera eficiente. Es una herramienta práctica para aportar evidencia empírica al Teorema de Aproximación Universal. El algoritmo queda de la forma:
```Plaintext
Initialize multi layer perceptron architecture
Initialize weights w to small random values
Set learning rate η

for a fixed number of epochs:
    For each training example μ in the dataset:
        1. Compute activation given by feed forward pass:
           Oⱼ = θ( ∑ₖ Vₖᴹ⁻¹ . wⱼₖᴹ ) ,

           k is the index of neuron from previous layer.
           sum is over the qty. of neurons from the previous layer.

        2. Update the weights and bias:
           For each weight wᵢ:
               wᵢ = wᵢ + Δwᵢ, where Δwᵢ = -η ∂E/∂wᵢ (gradient descendent)
               and ∂E/∂wᵢ is computed using backpropagation

        3. Calculate perceptron error:
           error = f(x^μ₁, x^μ₂, ..., x^μₙ)
           convergence = True if error < ε else False
           if convergence: break

End
```

Para este algoritmo tenemos distintas variantes:
- Incremental/Online: La actualización de los pesos de la red se hace luego de calcular el $\Delta w$ para un elemento del conjunto de datos.
- Mini Batch: La actualización de los pesos de la red se hace luego de calcular el $\Delta w$ para un subconjunto de elementos del conjunto de datos.
- Batch: La actualización de los pesos de la red se hace luego de calcular el $\Delta w$ para todos los elementos del conjunto de datos.

La versión batch introduce los siguientes cambios:
```Plaintext
Initialize multi layer perceptron architecture
Initialize weights w to small random values
Set learning rate η

for a fixed number of epochs:
    Δws = 0
    For each training example μ in the dataset:
        1. Compute activation given by feed forward pass:
           Oⱼ = θ( ∑ₖ Vₖᴹ⁻¹ . wⱼₖᴹ ) ,
           where j is the index of output neuron,
           M is the index of output layer,
           k is the index of neuron from previous layer.
           sum is over the qty. of neurons from the previous layer.

        2. Calculate the weights and bias:
           For each weight wᵢ:
               Δws = Δws + Δwᵢ, where Δwᵢ = -η ∂E/∂wᵢ (gradient descendent)
               and ∂E/∂wᵢ is computed using backpropagation

    w = w + Δws / batch size
    Calculate perceptron error:
        error = f(x^μ₁, x^μ₂, ..., x^μₙ)
        convergence = True if error < ε else False
        if convergence: break

End
```

## Métricas de Evaluación

Ahora, tenemos que ver de qué manera podemos medir el desempeño de nuestro modelo. Para evaluar la clasificación, existen una serie de métricas estándar que ya están definidas, por lo que debemos tener cuidado de no crear una propia y nombrarla exactamente igual. Algunas son:
- **Accuracy**: $\frac{\text{TP}+\text{TN}}{\text{TP}+\text{TN}+\text{FN}+\text{FP}}$  → puede presentar sesgos en casos donde hay pocas muestras, como por ejemplo en una enfermedad muy rara con pocos casos.
- **Precision**: $\frac{\text{TP}}{\text{TP}+\text{FP}}$ → mide la calidad del modelo, es decir la capacidad de evitar que las etiquetas negativas queden como positivas.
- **Recall**: $\frac{\text{TP}}{\text{TP}+\text{FN}}$ → informa sobre la cantidad de la clase positiva que el modelo identificó bien.
- **F1-Score**: $\frac{2\cdot\text{precision}\cdot\text{recall}}{\text{precision}+\text{recall}}$ → es una combinación de los anteriores.
- **Tasa de TP**: $\frac{\text{TP}}{\text{TP}+\text{FN}}$
- **Tasa de FP**: $\frac{\text{FP}}{\text{FP}+\text{TN}}$

Entonces, el procedimiento a realizar para un experimento es el siguiente, una vez que se tienen los dos conjuntos de datos definidos previamente (entrenamiento y prueba):
1. Calcular los $w$ utilizando el conjunto de entrenamiento.
2. Clasificar los datos del conjunto de prueba utilizando los $w$ encontrados en el paso 1.
3. Calcular el valor de las métricas para los ejemplos del conjunto de entrenamiento y luego para los del conjunto de prueba.

Realizar el mismo experimento para $\text{epoch} = 1, 10, 20, . . . , 300$.

## Optimización

Sabemos que el método del gradiente descendente nos da una dirección en la cual lograremos navegar esa superficie bajando cada vez el costo. Esa dirección es $\Delta W$. Pero hay una serie de mejoras que podemos introducir para lograr que nuestro modelo "aprenda más rápido".

El problema que tiene el método del gradiente descendente es que la información que dispone es local. Esto es, porque la dirección de descenso es, justamente, la derivada de $E(W)$ respecto a cada uno de los pesos de las conexiones en el punto obtenido hasta ese momento. En el siguiente caso, nos puede suceder quedarnos en el mínimo al que está llegando el modelo, justamente por esta condición de contar con información local.
![[Pasted image 20260712203205.png|center|251]]

El **momentum** es una técnica que toma la siguiente fórmula:
$$\Delta w_{ij}(t + 1) = -\eta \frac{\partial E}{\partial w_{ij}} + \alpha \Delta w_{ij}(t)$$
Donde $\alpha$ está entre 0 y 1. Los valores comunes para $\alpha$ son 0.8 o 0.9. Vemos que esto le da el envión que ya tiene de la iteración anterior a la actual, de allí su nombre.
- Si la función $E(\cdot)$ está en una región plana, $\Delta w_{ij}(t)$ será similar a $\frac{\partial E}{\partial w_{ij}}$, y por lo tanto $\Delta w_{ij}(t + 1)$ será un incremento en módulo de $\frac{\partial E}{\partial w_{ij}}$.
- Si la función $E(\cdot)$ está en un valle o en una región oscilatoria, $\Delta w_{ij}(t + 1)$ tenderá a compensarse para evitar oscilaciones.

El **Eta Adaptativo** es otra técnica que tiene la siguiente idea. Si, de forma consistente, $E(\cdot)$ decrece en un momento del aprendizaje (por ejemplo, durante $k$ iteraciones seguidas), quizás sería interesante incrementar $\eta$. Por otro lado, si $E(\cdot)$ comienza a incrementarse en un momento del aprendizaje (por ejemplo, durante $k'$ iteraciones seguidas), quizás sería interesante decrementar $\eta$ para evitar divergencia.

Esto se puede formalizar adaptando el valor de $\eta$ según:
$$\Delta \eta = \begin{cases} +a & \text{si } \Delta E < 0 \text{ en forma consistente} \\ -b\eta & \text{si } \Delta E > 0 \text{ empieza a ser consistente} \\ 0 & \text{en otro caso} \end{cases}$$

Cuando se dice "en forma consistente", en realidad se puede parametrizar de muchas formas. Por ejemplo, si en K épocas el error varía menos de $P\%$. Es importante definir cómo se contemplará.

Otro método es el **RMSProp**, que es una especie de Eta Adaptativo pero lo que hace es tener un $\eta$ distinto para cada peso de la red. La fórmula es la siguiente, donde $g_t$ es el gradiente en la época $t$.
$$\begin{gathered}g_t = \frac{\partial E}{\partial w_{ij}} \\[2ex] S_t = \gamma S_{t-1} + (1 - \gamma)g_t^2 \\[2ex] \Delta w_{ij} = -\frac{\eta}{\sqrt{S_t + \epsilon}} * g_t \end{gathered}$$
El término $g_t^2$ es el cuadrado aplicado miembro a miembro en el vector $g_t$ y el símbolo $\epsilon$ es un parámetro para evitar divisiones por cero (en las primeras iteraciones). Esto básicamente ajusta el learning rate de acuerdo a la root mean square (RMS). 
- Alta RMS: learning rate más bajo "amortigua" los cambios. Reduce "oscilaciones".
- Baja RMS: LR más alto evita mínimos locales, aprende más rápido.

Decimos RMS (Root Mean Square) y nos referimos a un promedio por lo siguiente:
$$
\begin{aligned}
\mathbf{s}_t &= (1 - \gamma)\mathbf{g}_t^2 + \gamma\mathbf{s}_{t-1} \\[2ex]
&= (1 - \gamma)\left(\mathbf{g}_t^2 + \gamma\mathbf{g}_{t-1}^2 + \gamma^2\mathbf{g}_{t-2}^2 + \dots\right).
\end{aligned}
$$
Al desarrollar varias iteraciones, toma la forma de un promedio. Los términos más recientes tienen más peso que los viejos.

El último método es **Adam**, que resulta de la combinación de RMSProp y Momentum, y es muy utilizado en la práctica. 
![[Pasted image 20260712204026.png|center|472]]

Vemos dentro del while que el $m_t$ y $v_t$ son términos que una vez definidos, se les corrige el sesgo (bias) introducido por los valores de $\beta$ elegidos, principalmente en las primeras iteraciones, dado que $m_t$ y $v_t$ comienzan en cero. Según el paper de esta técnica:

>[!QUOTE] Cita del Paper
>La configuración predeterminada recomendada para los problemas de aprendizaje automático probados es $\alpha = 0.001$, $\beta_1 = 0.9$, $\beta_2 = 0.999$ y $\epsilon = 10^{-8}$. Todas las operaciones en vectores se realizan elemento a elemento. Con $\beta_1^t$ y $\beta_2^t$ denotamos $\beta_1$ y $\beta_2$ elevados a la potencia $t$.

## Regularización

La **regularización** es un conjunto de técnicas diseñadas para reducir el error de test (o validación). Es decir, queremos disminuir el siguiente gap en el accuracy:
![[Pasted image 20260712204209.png|center|279]]
Busca bajar el error de generalización. No siempre acompañan el aprendizaje.

La **capacidad** de un modelo de Machine Learning es la habilidad o “potencial” de aproximar o alcanzar una variedad determinada de funciones. Algunas acciones que permiten cambiar capacidad son:
- elección de modelo
- arquitectura del modelo
- cant. de características que uso como input

Tomemos la siguiente imagen, donde se representa:
- Capacidad (Eje X): Es la complejidad del modelo. A mayor capacidad, el modelo puede representar funciones más complejas (por ejemplo, pasar de una línea recta a un polinomio de grado 10 o a una red neuronal con miles de neuronas).
- Error (Eje Y): Representa el costo o la pérdida del modelo.

![[Pasted image 20260712204328.png|center|474]]

En el error de entrenamiento (línea punteada rosa), a medida que aumenta la Capacidad, este error siempre disminuye. Un modelo con mucha capacidad tiene el "potencial" de ajustarse perfectamente a los datos que ya conoce, incluso memorizándolos.  El error de generalización (línea sólida verde) muestra cómo se comporta el modelo ante datos nuevos. Tiene forma de U, ya que baja al principio, pero vuelve a subir cuando el modelo se vuelve demasiado complejo.

La **Brecha de Generalización** es la distancia vertical entre ambas curvas. Si la brecha es pequeña, indica que el modelo se comportará de forma similar con datos nuevos que con los de entrenamiento. Si la brecha es grande, es el síntoma claro de Overfitting. El modelo "sabe mucho" de sus datos de práctica pero no entiende nada del mundo real.

El **Punto Óptimo de Capacidad** es el momento exacto en el que el modelo ha dejado de ser demasiado simple (bajo sesgo), pero aún no ha empezado a volverse "paranoico" con el ruido de los datos (baja varianza). Las técnicas de regularización ayudan en la parte “derecha” de la imagen previa. 

El **Early Stopping** es la primera técnica de regularización, y es de las más simples y efectivas en el entrenamiento de redes neuronales. Su objetivo es detener el proceso de aprendizaje en el momento justo antes de que el modelo empiece a hacer overfitting. Para aplicarlo, se dividen los datos en Entrenamiento, Validación y Testeo. El algoritmo sigue estos pasos:
1. Durante el entrenamiento, al final de cada época (epoch), se calcula el error (loss) tanto en el set de entrenamiento como en el de validación.
2. Al principio, ambos errores bajan. El modelo está aprendiendo.
3. Llega un punto donde el error de entrenamiento sigue bajando (porque la red se ajusta cada vez más a esos datos específicos), pero el error de validación se estanca o empieza a subir.
4. Cuando el error de validación aumenta durante un número determinado de épocas (a esto se le llama patience o paciencia), el algoritmo detiene el entrenamiento automáticamente.
5. Generalmente, el algoritmo devuelve los pesos que tenía la red en el punto donde el error de validación fue el mínimo absoluto, no los del final.

**Data Augmentation** es un conjunto de técnicas utilizadas para incrementar artificialmente el tamaño y la diversidad de un conjunto de datos de entrenamiento sin necesidad de recolectar datos nuevos reales. Se logra aplicando transformaciones aleatorias a los datos ya recolectados, de modo que el modelo vea una versión ligeramente distinta de la misma información en cada época.
![[Pasted image 20260712204440.png|center|178]]

Es muy utilizado en clasificación de objetos:
- Agregado de ruido (gaussiano)
- Rotaciones
- Traslaciones
- Cambios de escala
- etc.

**L2 Penalty Norm / Weight Decay** es otra técnica de regularización fundamental. Mientras que el Early Stopping actúa sobre el tiempo de entrenamiento y el Data Augmentation sobre los datos, esta actúa directamente sobre los pesos w de la red. Consiste en modificar la función de costo original ($E$) agregándole un término que "castiga" a los pesos grandes.
$$w_{\text{nuevo}} = w_{\text{anterior}}(1 - \eta\lambda) - \eta \frac{\partial E}{\partial w}$$
Donde $\lambda$ es el coeficiente de regularización. Controla qué tan fuerte es la penalización.

Supongamos que estamos entrenando un modelo para predecir si un comentario sobre una película es positivo o negativo. Tenemos 5 entradas (features):
![[Pasted image 20260712204620.png|center|425]]

Las variables útiles (Círculos Violetas)
1. Ratio de palabras positivas
2. Signos de exclamación
3. Cantidad de palabras

El "Ruido" o variables irrelevantes (Círculos Rojos)
1. Fuente utilizada
2. Ancho de pantalla del dispositivo

Si el dataset de entrenamiento es chico, por pura casualidad podría pasar que los 5 comentarios más positivos justo se escribieron desde pantallas anchas. Esto es overfitting: la red encontró una regla que funciona en la tabla de datos, pero que es mentira en el mundo real. Como vimos, la L2 castiga los pesos grandes. Entonces, le pone un "precio" a usar cada variable. La red intenta subir el peso del "Ancho de pantalla" porque vio una correlación casual. Como el "Ancho de pantalla" realmente no ayuda a predecir el sentimiento de forma consistente, la red decide que no vale la pena pagar la multa y achica el peso (w) casi a cero.
