## Definición

Un **string** en C es un arreglo (_array_) de caracteres que sí o sí tiene un cero (`\0`) al final, por lo que se dice que es _null terminated_. Pueden existir cadenas constantes que se almacenan en una zona de memoria dedicada de solo lectura donde no es posible modificarlas (como el _Text Segment_ o _Data Segment_).

Formando una definición más precisa: una constante de tipo string es un arreglo de `char` sin nombre, por lo que ella misma representa la dirección de memoria de su primera componente. En el caso del literal `"Hola mundo"`, se guarda la dirección de la `'H'` y los caracteres continúan secuencialmente hasta el carácter nulo (`\0` o `0`) que indica dónde finaliza.

Las constantes literales sirven principalmente para:
- Inicializar punteros a `char`:
    ```c
    char * texto = "Hola";
    ```
- Asignar punteros a `char`:
    ```c
    char * texto;
    texto = "Hola";
    ```
- Pasar como argumento de función:
    ```c
    printf("Hola");
    ```
- Hacer aritmética de punteros / referencias:
    ```c
    printf("%s", "Hola" + 2);
    ```

En este último caso, `printf("%s", "Hola" + 2);` va a imprimir `"la"`, porque en lugar de apuntar a la dirección de la `'H'`, se le suman 2 posiciones y se obtiene la dirección de la `'l'`.

Al desreferenciar o indexar punteros a caracteres, se aplican las equivalencias habituales de la aritmética de punteros:
```c
putchar(*texto);        // Equivale a texto[0]
putchar(texto[2]);      // Equivale a *(texto + 2)
```

Tener en cuenta que expresiones como `2[texto]` equivalen sintácticamente a `*(2 + texto)`, aunque son formas poco comunes y desaconsejadas por legibilidad.

>[!TIP] Importante
>Es importante recordar que `'\0'` es numéricamente lo mismo que `0`.

Es clave no confundir los siguientes dos conceptos:
1. `char * texto = "Hola mundo";` $\rightarrow$ `texto` es una variable puntero que almacena la dirección de memoria donde está guardada la cadena constante en una zona de solo lectura.
2. `int * valor = 548;` $\rightarrow$ Intenta asignar directamente una dirección absoluta (548) a un puntero, lo cual suele ser invalido o apuntar a memoria arbitraria/desconocida.

Las "variables" de tipo string como tal son arreglos de `char`. Se pueden inicializar elemento por elemento:
```c
char msg1[] = {'H', 'o', 'l', 'a', ' ', '!', 0};
char msg2[10] = {'H', 'E', 'L', 'L', 'O', 'W', '!'};
```

En `msg1`, agregamos explícitamente un `0` (o `'\0'`) al final porque no detallamos la dimensión del arreglo. En `msg2`, al especificar un tamaño fijo de 10 elementos mayor que la cantidad de caracteres provistos, los elementos restantes del arreglo se completan automáticamente con ceros (`\0`).

Existe una forma abreviada para declarar arreglos modificables:
```c
char text[] = "Hola";
```

Pero **NO** es una constante en memoria de solo lectura. Es decir, no es lo mismo que:
```c
char * text = "Hola";
```

El primer caso (`char text[]`) aloca espacio en el _stack_ para los caracteres más el nulo (guarda 5 bytes en total). El segundo caso (`char * text`) asigna un puntero en el _stack_ (que ocupa los bytes de una dirección de memoria) apuntando a la zona de texto/datos de solo lectura donde residen los 5 bytes de `"Hola\0"`.

Analizando las diferencias de modificación y reasignación entre un arreglo y un puntero a string constante:
```c
char hi[] = "hola";
char * bye = "adios";

hi[0] = 'H';   // VÁLIDO: Cambia 'h' por 'H' en la memoria local (Stack).
bye[0] = 'A';  // ERROR: Compila y linkea pero falla en tiempo de ejecución (Segmentation Fault) porque intenta modificar memoria constante (Data/Text Segment).
bye = hi;      // VÁLIDO: Cambia la dirección contenida en 'bye' para que apunte al arreglo 'hi'.
hi = bye;      // ERROR: 'hi' es el nombre de un arreglo (no es un l-value modificable), funciona como un rótulo fijo a su dirección. No compila.
```

Para construir o modificar arreglos dinámicamente mediante punteros y sintaxis de arreglos, se puede operar sobre espacio reservado:
```c
char * pCadena;
char cadena[5];

pCadena = cadena;
*pCadena = '1';
*(pCadena + 1) = '2';
*(pCadena + 2) = 0; // Termina la cadena con el delimitador nulo
```

O directamente sobre el propio arreglo usando la sintaxis de punteros:
```c
char cadena[5];

*cadena = '1';
*(cadena + 1) = '2';
*(cadena + 2) = 0;
```

Al trabajar con cadenas dentro de funciones, se debe prestar especial atención al pasaje de parámetros. Dado el siguiente código:
```c
void printUpper(char vector[]);

int main(void) {
    char text[] = "Hola mundo";
    printUpper(text);
    return 0;
}

void printUpper(char vector[]) {
    int len;
    len = sizeof(vector); // ERROR de lógica
    for (int i = 0; i < len; i++) {
        putchar(toupper(vector[i]));
    }
}
```

El problema está en el uso de `sizeof(vector)`. Cuando un arreglo se pasa como parámetro a una función, este "decae" a un puntero (`char *`). Por lo tanto, `sizeof(vector)` no devuelve el tamaño del arreglo en bytes ni la cantidad de caracteres, sino el tamaño del puntero (normalmente 4 u 8 bytes según la arquitectura).

Si corregimos el código usando `strlen()` de `<string.h>`:
```c
void printUpper(char vector[]) {
    int len = strlen(vector);
    for (int i = 0; i < len; i++) {
        putchar(toupper(vector[i]));
    }
}
```

Este código funciona y es claro, pero no es del todo eficiente. `strlen()` realiza un recorrido completo previo del vector para calcular su longitud, y luego el ciclo `for` vuelve a recorrer el arreglo por segunda vez para procesar cada carácter.

Para optimizarlo y hacerlo verdaderamente eficiente en una sola pasada, aprovechamos que la cadena es _null terminated_ procesando los elementos hasta encontrar el `'\0'`:
```c
void printUpper(char vector[]) {
    for (int i = 0; vector[i] != '\0'; i++) {
        putchar(toupper(vector[i]));
    }
}
```

O de forma aún más idiomática aprovechando punteros:
```c
void printUpper(char * vector) {
    while (*vector != '\0') {
        putchar(toupper(*vector));
        vector++;
    }
}
```

## Librería Estándar `string.h`

La **librería estándar `<string.h>`** provee diversas funciones para la manipulación de cadenas de caracteres en C. Las firmas principales de estas funciones son:
```c
size_t strlen(const char * s);
char * strcpy(char * t, const char * s);
char * strncpy(char * t, const char * s, size_t n);
char * strcat(char * t, const char * s);
char * strncat(char * t, const char * s, size_t n);
int strcmp(const char * t, const char * s);
int strncmp(const char * t, const char * s, size_t n);
char * strchr(const char * s, int c);
char * strrchr(const char * s, int c);
char * strpbrk(const char * s, const char * set);
char * strstr(const char * t, const char * s);
int strcasecmp(const char * s1, const char * s2); // Disponible en POSIX / strings.h
```

A continuación se detalla el comportamiento de cada una de ellas:
- `strlen`: Devuelve la longitud del string (cuenta la cantidad de caracteres sin incluir el `\0` final).
- `strcpy`: Copia el string apuntado por `s` en el destino `t` (incluyendo el `\0` final). Retorna el puntero al destino `t`, aunque habitualmente se invoca ignorando el valor de retorno como si fuera `void`.
- `strncpy`: Copia un string limitado a un máximo de `n` caracteres. Presenta dos comportamientos clave según la longitud del origen:
    - Si el string de origen es más largo o igual a `n`, copia exactamente `n` caracteres y **NO** agrega el `\0` final automáticamente.
    - Si el string de origen es más corto que `n`, copia el string completo (incluyendo el `\0`) y rellena el resto de los `n` bytes en el destino con ceros (`\0`). Por ejemplo, con la llamada `strncpy(v, "abcdefg", 5)`, al ser la cadena más larga que 5, solo se copian `'a'`, `'b'`, `'c'`, `'d'`, `'e'` sin incluir delimitador nulo al final. En cambio, con `strncpy(v, "ab", 5)`, se copian `'a'`, `'b'`, `'\0'` y se completa el espacio sobrante con ceros hasta alcanzar los 5 bytes: `'a'`, `'b'`, `'\0'`, `'\0'`, `'\0'`.
- `strcat`: Concatena el string `s` al final de `t`. Sobrescribe el carácter `\0` que marcaba el final de `t` con el primer carácter de `s` y agrega un nuevo `\0` al terminar la copia.
- `strncat`: Es igual a `strcat`, pero limita la concatenación a un máximo de `n` caracteres desde `s`, asegurándose siempre de añadir el carácter nulo `\0` al final.
- `strcmp`: Compara alfabéticamente/lexicográficamente dos cadenas de caracteres. Devuelve `0` si ambas son exactamente iguales en contenido y longitud. Devuelve un valor menor a cero (`< 0`) si el primer carácter que difiere en `t` tiene un valor ASCII menor que el de `s`, o un valor mayor a cero (`> 0`) en caso contrario.
- `strncmp`: Compara únicamente los primeros `n` caracteres de dos cadenas. Es muy útil para verificar si una palabra empieza con un prefijo determinado.
- `strchr`: Busca la primera aparición del carácter `c` dentro del string `s`. Si lo encuentra, devuelve un puntero apuntando a esa posición de memoria dentro de la cadena; si no existe el carácter, devuelve `NULL`.
- `strrchr`: Similar a `strchr`, pero realiza la búsqueda empezando desde el final de la cadena hacia el principio (devuelve la última aparición del carácter).
- `strpbrk`: Busca en `s` la primera aparición de cualquier carácter contenido en el conjunto `set`. Si le pasamos `"abc"`, devolverá un puntero al lugar donde encuentre por primera vez una `'a'`, una `'b'` o una `'c'`.
- `strstr`: Busca la primera ocurrencia de la subcadena completa `s` dentro del string `t` y retorna el puntero a su inicio, o `NULL` si no la encuentra.
- `strcasecmp`: Compara dos cadenas de la misma manera que `strcmp`, pero sin distinguir entre mayúsculas y minúsculas (_case-insensitive_).

Para analizar el comportamiento práctico de la memoria durante las operaciones con cadenas, consideremos la siguiente secuencia de código:
```c
char cad1[8], cad2[10];
char *resp;

strcpy(cad2, "prueba");
resp = strcpy(cad1, cad2);
printf("cad1=%p cad2=%p resp=%p\n", cad1, cad2, resp);
printf("cad1=%s cad2=%s resp=%s\n", cad1, cad2, resp);

strcpy(cad2, "otra vez");
cad2[3] = 0;
strcpy(cad1, cad2);
resp = strchr(cad1, 'a');
strcat(cad1, cad2);
resp = strchr(cad1, 'r');
```

Usar `%s` en el `printf` resulta equivalente en comportamiento al uso de la función `puts()`. Luego, al hacer `strcpy(cad2, "otra vez")`, se copian los caracteres de la nueva cadena sobre `cad2`.

## Función `scanf`

La función `scanf` (declarada en `<stdio.h>`) nos sirve para leer datos desde la entrada estándar (`stdin`). Es, en cierto modo, la contraparte de `printf`. Acepta especificadores de formato similares a los de `printf`, pero con consideraciones clave al trabajar con cadenas de caracteres:
- `%s` lee una secuencia de caracteres que se interrumpe al encontrar el primer espacio en blanco (espacio, tabulación o salto de línea `\n`).
- Para limitar la cantidad de caracteres leídos y evitar desbordamientos de búfer (_buffer overflow_), se puede especificar un ancho máximo mediante `%Xs` (por ejemplo, `%9s` lee hasta 9 caracteres y reserva lugar para el `\0` final).
- Si se desea incluir espacios dentro del texto leído, en lugar de `%s` se utilizan los especificadores de conjunto de escaneo (_scansets_) mediante corchetes `[...]`.

`scanf` retorna un número entero que representa la cantidad de variables que pudieron leerse y asignarse con éxito.
```c
int d, m, y, cant;
printf("Ingrese fecha[dd/mm/aa]: ");
cant = scanf("%d/%d/%d", &d, &m, &y);
```

Si el usuario ingresa `15/08/2024`, `cant` va a valer `3`. Si se ingresa un formato inválido como `1/a/2020`, `cant` va a valer `1`, ya que el proceso de lectura se interrumpe exactamente donde falla la coincidencia (al intentar leer `a` como entero `%d`).

Lo que no se pudo procesar (`a/2020`) permanece guardado en el búfer de entrada. Si hiciéramos un ciclo como `while(cant != 3)` reintentando llamar a `scanf` sin limpiar la entrada, entraríamos en un bucle infinito porque `scanf` volverá a fallar al leer repetidamente el mismo carácter no numérico del búfer. Para limpiar el búfer hasta el siguiente salto de línea se puede consumir el resto del flujo con `getchar()`:
```c
while (getchar() != '\n');
```

Los especificadores de conversión con corchetes (_scansets_) permiten definir conjuntos de caracteres permitidos `[...]` o excluidos `[^...]`:
- `scanf("%[ABC]", s)` lee caracteres únicamente mientras pertenezcan al conjunto `{A, B, C}`.
- `scanf("%[0-9]", s)` o `scanf("%[0123456789]", s)` lee secuencias formadas solo por dígitos.
- `scanf("%[^\n]", s)` lee toda la línea hasta encontrar un salto de línea (una forma común de incluir espacios).

En el siguiente ejemplo:
```c
char s1[10], s2[10];
printf("Ingrese dos números: ");
scanf("%[0123456789] %[0-9]", s1, s2);
```

Ambas expresiones `[0123456789]` y `[0-9]` son sintácticamente equivalentes para denotar el rango de dígitos. Siempre es una buena práctica verificar el valor de retorno de `scanf` para asegurar que ambos strings hayan sido leídos correctamente.

Los conjuntos de escaneo o _scansets_ (`[...]` y `[^...]`) son herramientas de `scanf` para controlar exactamente qué caracteres se aceptan o rechazan al leer una cadena:
- **Conjunto de inclusión `[...]`:** Lee caracteres de la entrada únicamente mientras pertenezcan al grupo definido entre los corchetes. En cuanto el compilador encuentra un carácter que no está en la lista, la lectura de esa variable se detiene. Por ejemplo, `[ABC]` solo acepta las letras A, B y C (en mayúscula), mientras que `[0-9]` acepta cualquier dígito numérico. Se pueden combinar rangos como `[a-z.?X]` para incluir minúsculas, puntos, signos de interrogación y la letra X.
- **Conjunto de exclusión `[^...]`:** El símbolo `^` al inicio invierte la lógica, funcionando como un filtro de rechazo. Lee todos los caracteres que vengan en la entrada **hasta** encontrar alguno de los especificados dentro de los corchetes. El caso más típico es `[^\n]`, que lee todo el texto con espacios incluidos y solo se detiene al presionar _Enter_ (el salto de línea). Si pones `[^0-9]`, leerá todo hasta que aparezca el primer número.

Consideremos la lectura de una patente o matrícula:
```c
char license[7];
printf("Ingrese la patente de su auto: ");
scanf("%6[0-9A-Z]", license);
```

Si quisiéramos validar una patente clásica de formato tres letras y tres números (como `AAA999`), `%6[0-9A-Z]` no basta, ya que aceptaría secuencias desordenadas como `A9A9A9`.

Para forzar la estructura exacta, podemos dividir la especificación especificando anchos exactos: `%3[A-Z]%3[0-9]`. Esto leerá exactamente 3 letras seguidas de 3 números. Además, se debe validar que el número total de caracteres leídos cumpla la longitud esperada mediante `strlen` y verificar el valor devuelto por `scanf`:
```c
int cant;
do {
    // Limpia el búfer en caso de reintento si quedaron caracteres remanentes
    cant = scanf("%3[A-Z]%3[0-9]", license);
    if (cant != 2) {
        while (getchar() != '\n'); // Limpia el búfer si la lectura falló
    }
} while (cant != 2 || strlen(license) != 6);
```

Al comparar las siguientes dos formas de imprimir una cadena almacenada en `s`:
```c
// Caso 1:
char s[MAX];
scanf("%s", s);
printf("%s", s);

// Caso 2:
char s[MAX];
scanf("%s", s);
printf(s);
```

Ambos fragmentos logran imprimir la cadena almacenada en `s`.

>[!WARNING] Vulnerabilidad de Cadena de Formato
>El Caso 2 (`printf(s)`) representa un riesgo severo de seguridad conocido como **vulnerabilidad de cadena de formato** (_Format String Vulnerability_). Si la cadena `s` ingresada por el usuario contiene caracteres de especificación como `%s`, `%x` o `%n`, `printf` intentará interpretarlos leyendo datos arbitrarios de la pila (_stack_). La forma correcta e incondicional para imprimir variables tipo string es siempre la del Caso 1 (`printf("%s", s)`) o bien utilizando `fputs(s, stdout)`.

## Conjunto de Strings

Para definir un **conjunto de strings** (o arreglo de cadenas) en C, una de las formas es mediante una matriz de caracteres (un arreglo bidimensional).
```c
char palos[][7] = {"Copa", "Basto", "Oro", "Espada"};
```

Se especifica el número `7` en la segunda dimensión porque esta define la capacidad máxima de caracteres (incluyendo el `\0` final) de cada elemento individual del arreglo. Como la palabra más larga es `"Espada"` (6 caracteres + 1 para el delimitador nulo `\0`), se necesitan al menos 7 bytes por fila.
![[Pasted image 20260726211700.png|center]]

En aquellas filas donde la palabra es más corta y "sobra" espacio (como en `"Oro"` o `"Copa"`), las posiciones restantes de esa fila en la matriz se completan automáticamente con ceros (`\0`).

Si intentáramos definir `palos[][5]` en lugar de `palos[][7]`, se produciría un error o _warning_ de compilación, ya que la palabra `"Espada"` no entraría al requerir 7 bytes mínimos.

>[!INFO] Desventaja 
>La principal desventaja de este enfoque con matrices de tamaño fijo es que desperdiciamos memoria en las palabras más cortas, ya que todas las filas quedan obligadamente reservadas con la misma cantidad de bytes independientemente de la longitud real del string que almacenen.

## Arreglo de Punteros a Caracteres

Para solucionar el problema del desperdicio de memoria que generan las matrices de caracteres fijas, podemos utilizar un **arreglo de punteros a caracteres**:
```c
char * palos[] = {"Copa", "Basto", "Oro", "Espada"};
```

Con este enfoque se crea un vector donde cada posición almacena únicamente la dirección de memoria (_puntero_) donde reside el string correspondiente. Los literales de cadena (`"Copa"`, `"Basto"`, etc.) se alojan en la zona de memoria constante/solo lectura (_Data Segment_) ajustándose exactamente a la longitud de cada palabra más su `\0`. Por su parte, el vector `palos` que contiene las direcciones de memoria reside en la pila (_stack_). Al ser punteros a constantes literales, los caracteres individuales de estas cadenas no se pueden modificar.
![[Pasted image 20260726220751.png|center|537]]

Para imprimir los elementos de este arreglo de punteros, recorremos el vector y pasamos cada puntero `palos[i]` como argumento:
```c
for (int i = 0; i < 4; i++) {
    printf("%s\n", palos[i]);
}
```

La elección entre una matriz de caracteres `char palos[][N]` y un vector de punteros `char * palos[]` depende del problema:
- La **matriz de caracteres** nos permite modificar los caracteres de las cadenas directamente y mantenerlas contiguas en memoria.
- El **vector de punteros** ahorra espacio al evitar el padding con ceros y resulta óptimo para tareas como ordenar alfabéticamente, ya que solo requiere intercambiar direcciones de memoria (punteros) en lugar de copiar bloques enteros de texto carácter por carácter.

Analicemos la salida del siguiente ejercicio basado en la estructura en memoria indicada:
```c
char * palos[] = {"Copa", "Basto", "Oro", "Espada"};

printf("%p\n", palos[2]);
printf("%s\n", palos[2]);
printf("%c\n", palos[2][0]);
printf("%c\n", palos[2]);
printf("%c\n", **palos);
```
1. `printf("%p\n", palos[2]);`: Imprime la dirección de memoria almacenada en el índice 2 de `palos` (que apunta al inicio de `"Oro"`, por ejemplo `A00F`).
2. `printf("%s\n", palos[2]);`: Imprime la cadena completa apuntada por `palos[2]`, es decir, `"Oro"`.
3. `printf("%c\n", palos[2][0]);`: Accede al primer carácter del string en la posición 2 y lo imprime, resultando en la letra `'O'`.
4. `printf("%c\n", *palos[2]);`: Desreferencia el puntero `palos[2]` obteniendo su primer carácter, que también es `'O'`.
5. `printf("%c\n", **palos);`: `palos` decae a un puntero al primer elemento (`&palos[0]`). Al desreferenciarlo dos veces (`**palos`), se obtiene el primer carácter del primer string, imprimiendo la `'C'` de `"Copa"`.

Asumiendo que declaramos las cadenas como arreglos modificables para permitir transformaciones (por ejemplo, `char palo[][10]` o pasándolas como parámetros no constantes `char palo[][10]` / `char *paloFr[]`), existen distintas sintaxis válidas e inválidas para operar sobre los caracteres o modificar sus elementos:
```c
// Tres formas sintácticamente equivalentes y válidas para acceder al primer carácter de la primera cadena y pasarlo a minúscula:
palo[0][0] = tolower(palo[0][0]);
*palo[0]   = tolower(*palo[0]);
**palo     = tolower(**palo);
```

Revisando la validez de las siguientes expresiones habituales:
- `paloFr[0] = toupper(paloFr[0]);` $\rightarrow$ **INCORRECTO**: `paloFr[0]` es un puntero o un subarreglo (`char *`), no un carácter único (`char`), por lo que no puede pasarse a `toupper()` ni asignarse directamente a un valor entero.
- `paloFr[0][0] = tolower(paloFr[0][0]);` $\rightarrow$ **CORRECTO**: Accede correctamente al primer carácter como `char` y lo modifica.
- `paloFr[0] = palo[0];` $\rightarrow$ **INCORRECTO** si `paloFr` es una matriz fija (los nombres de arreglos fijos no son _l-values_ asignables). Sería **CORRECTO** si `paloFr` fuera un vector de punteros `char * paloFr[]` donde sí se pueden reasignar las direcciones a las que apunta cada índice.
- `palo[0] = NULL;` $\rightarrow$ **CORRECTO** si `palo` es un arreglo de punteros `char * palo[]`. **INCORRECTO** si `palo` es una matriz bidimensional `char palo[][N]`.
- `paloFr[1][10] = 0;` $\rightarrow$ **INCORRECTO** si la dimensión de la segunda columna es menor a 11, ya que generaría un acceso fuera de los límites del arreglo (_out of bounds_).
- `**(paloFr + 1) = 'X';` $\rightarrow$ **CORRECTO**: `(paloFr + 1)` avanza al segundo string, y al desreferenciar dos veces (`**`) accede y modifica su primer carácter asignándole `'X'`.

A la hora de escribir código, muchas veces resulta sintácticamente equivalente usar notación de corchetes `[][]` o de asteriscos `**`. Por claridad y mantenibilidad de la lectura, conviene priorizar el uso de corchetes `[]`.

## Función `sprintf`

La función `sprintf` (declarada en `<stdio.h>`) funciona de manera análoga a `printf`, pero en lugar de enviar el texto formateado a la salida estándar (`stdout`), escribe el resultado formateado directamente en un búfer o cadena de caracteres en memoria.

Su firma es:
```c
int sprintf(char * s, const char * fmt, ...);
```

El primer parámetro (`s`) es un puntero al arreglo de caracteres donde se guardará la cadena formateada. La función se encarga de agregar automáticamente el carácter delimitador nulo (`\0`) al final del texto generado. Devuelve la cantidad de caracteres escritos (sin contar el `\0`).

Ejemplo de invocación:
```c
char s[40];
sprintf(s, "%d/%d", 10, 15);
```

Con esto, en lugar de mostrar en pantalla, se guardan secuencialmente los códigos ASCII de los caracteres `'1'`, `'0'`, `'/'`, `'1'`, `'5'`, y el delimitador `'\0'` dentro del arreglo `s` (quedando almacenada la cadena `"10/15"`).

> [!WARNING] Límites de Memoria
> 
> `sprintf` no verifica si el arreglo de destino tiene espacio suficiente para albergar la cadena resultante. Si el texto resultante supera la capacidad del vector `s`, se producirá un desbordamiento de búfer (_buffer overflow_).  

Para evitar este problema, es recomendable utilizar su variante segura `snprintf`, la cual recibe como argumento el tamaño máximo del búfer de destino:
```c
snprintf(s, sizeof(s), "%d/%d", 10, 15);
```

## Función `sscanf`

La función `sscanf` (declarada en `<stdio.h>`) es la contraparte de `sprintf`: en lugar de leer datos desde la entrada estándar (`stdin`), extrae y parsea información directamente desde un string pasado como parámetro.

Su firma es:
```c
int sscanf(const char * s, const char * fmt, ...);
```

Funciona de manera idéntica a `scanf`, analizando el texto almacenado en el string `s` según los especificadores dados en `fmt` y guardando los valores leídos en las variables pasadas por referencia. Devuelve la cantidad de datos parseados con éxito.

A continuación se presenta un ejemplo para construir dinámicamente el formato de lectura de `scanf` y leer un string de forma segura limitando la cantidad de caracteres:
```c
int n;
char fmt[10];

do {
    n = getint("Longitud máxima: ");
} while (n < 1);

char orig[n + 1];
sprintf(fmt, "%%%ds", n);
scanf(fmt, orig);

char copia[strlen(orig) + 1];
strcpy(copia, orig);
```

Obtenemos con `getint` el máximo de caracteres deseado (`n`), y declaramos el arreglo `orig` con un tamaño de `n + 1` bytes para garantizar espacio suficiente para el carácter nulo (`\0`).

Con `sprintf(fmt, "%%%ds", n)` construimos dinámicamente la cadena de formato dentro de `fmt`:
- `%%` escribe el carácter literal `%` en la cadena.
- `%d` se reemplaza por el valor numérico de `n` (la longitud máxima).
- `s` agrega el carácter `s` al final.

Si por ejemplo `n` vale 12, la llamada a `sprintf` genera el string `"%12s"` dentro de `fmt`. Luego, al hacer `scanf(fmt, orig)`, equivale a ejecutar `scanf("%12s", orig)`. De esta forma logramos que `scanf` lea como máximo 12 caracteres desde la entrada estándar, evitando un desbordamiento de búfer. Finalmente, se calcula la longitud real con `strlen(orig) + 1` para alocar el tamaño exacto necesario en el vector `copia` y duplicar la cadena leída mediante `strcpy`.
