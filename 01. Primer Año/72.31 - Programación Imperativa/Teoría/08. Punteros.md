## Introducción

Para entender la necesidad de los punteros en C, se analiza un problema clásico: intercambiar los contenidos de dos variables (`dato1` y `dato2`). Consideremos el siguiente intento de función `swap`:
```c
void swap(int num1, int num2)
{
    int aux;
    aux = num1;
    num1 = num2;
    num2 = aux;
}

int main(void)
{
    int i = 2, j = 4;
    swap(i, j);
    return 0;
}
```

Esta función NO funciona para el propósito deseado. En C, los parámetros escalares se pasan por valor, lo que significa que a `swap` se le envían copias de los valores de `i` y `j`. Dentro del marco de pila (_stack frame_) de la función `swap`, las variables locales `num1` y `num2` intercambian sus valores en la memoria local, pero las variables originales `i` y `j` en el `main` permanecen intactas (`i = 2` y `j = 4`).

Un dilema similar ocurre al intentar implementar una función que simplifique una fracción:
```c
void simplifica(int num, int den)
{
    int aux;
    aux = mcd(num, den);
    printf(......);
}
```

En este diseño, la función `simplifica` se ve obligada a imprimir directamente los resultados por pantalla mediante `printf`. Esto impide separar el frontend (interfaz/pantalla) del backend (lógica de negocio). Lo correcto en un diseño modular es que la función modifique los valores de numerador y denominador en la memoria del programa principal, permitiendo que sea el `main` o la capa superior quien decida cómo presentarlos.

Aprovechando que los arreglos se pasan por dirección base, se podría intentar solucionar el problema de `swap` utilizando un vector como contenedor de dos posiciones:
```c
void swap(int vector[2])
{
    int aux;
    aux = vector[0];
    vector[0] = vector[1];
    vector[1] = aux;
}
```

Esta alternativa sí funciona físicamente, ya que a la función se le transmite la dirección de memoria inicial del vector (`FFF0`), permitiéndole modificar directamente el contenido almacenado en el mapa de memoria. Sin embargo, esta solución es semánticamente incorrecta por varias razones:
- Obliga a agrupar dos variables independientes dentro de un arreglo.
- Solo se transmite explícitamente la dirección del primer elemento (`vector[0]`), mientras que la posición del segundo elemento (`vector[1]`) se deduce por cálculo de desplazamiento contiguo ("está pegado" en memoria).

Sería mucho más limpio y directo poder enviar a la función las direcciones de memoria de variables independientes para modificarlas libremente, exactamente igual que ocurre con los vectores. La ventaja fundamental de este enfoque sobre el uso de arreglos es que se le transfiere a la función la dirección de la primera variable y la dirección de la segunda variable de forma explícita e independiente. La función no necesita calcular la ubicación del segundo dato por contigüidad en memoria, sino que recibe directamente las referencias a los l-values de ambas variables. Para lograr esta flexibilidad sin forzar el uso de arreglos, C introduce el concepto de **punteros**.

## Definición

Un **puntero** es una variable cuyo propósito es almacenar la dirección de memoria de otra variable. De esta forma, un puntero provee un mecanismo de acceso indirecto hacia el valor contenido en dicha posición. Más técnicamente, el _right value_ (contenido) de un puntero es el _left value_ (dirección de memoria) de una variable. La sintaxis general para definir un puntero es:
```c
tipoApointed * nombrePuntero;
```

Donde `tipoApointed` especifica el tipo de dato de la variable a la cual el puntero va a referenciar. Algunos ejemplos de declaración son:
```c
char   * pChar;   /* Puntero a char */
int    * intPunt; /* Puntero a int */
double * Punt_d;  /* Puntero a double */
```

Cada variable puntero funciona como una "cajita" destinada exclusivamente a guardar una dirección de memoria. Por lo tanto, independientemente del tipo de dato apuntado (`char`, `int`, `double`, etc.), el resultado de evaluar `sizeof(puntero)` será siempre el mismo para todos los punteros en una misma arquitectura.

El compilador le asigna la cantidad de bytes requerida por el procesador para almacenar una dirección de memoria:
- En arquitecturas de 32 bits, un puntero ocupa **4 bytes**.
- En arquitecturas de 64 bits (como el servidor Pampero), un puntero ocupa **8 bytes**.

A pesar de que todos los punteros ocupan la misma cantidad de bytes en memoria, es indispensable declarar el tipo apuntado (`char *`, `int *`, etc.) para que el compilador sepa cuántos bytes debe interpretar/desplazar al momento de acceder o realizar aritmética sobre el valor al que se apunta.

Al declarar múltiples variables en una misma línea, el asterisco `*` se aplica únicamente al identificador que lo sucede directamente, no al tipo de dato.
```c
int * p1, p2;  // ATENCIÓN: p1 es un puntero a int, pero p2 es un entero escalar
int * p1, *p2; // CORRECTO: tanto p1 como p2 son punteros a int
```

En el primer ejemplo (`int * p1, p2;`), `p1` y `p2` tienen tipos de datos diferentes (`p1` es `int *` mientras que `p2` es `int`). Por ello, para declarar múltiples punteros en una sola instrucción, es obligatorio anteponer un asterisco a cada uno de los nombres (`*p1, *p2`).

En cuanto al estilo de escritura, el espacio en blanco entre el asterisco y el nombre de la variable es opcional: se puede escribir separado (`* p1`) o pegado al identificador (`*p2`), siendo esta última la convención más recomendada para evitar confusiones al declarar variables múltiples.

## Operador Unario `&`

El operador unario `&` se aplica sobre un _l-value_ (una variable o posición que posee una ubicación física en memoria) y devuelve como resultado la dirección de memoria exacta donde dicho _l-value_ se encuentra almacenado.
```c
char letra = 'P';
float altura = 17.4;
int edad[2] = {25, 12};
```

Al evaluar la dirección de estas variables:
- `&letra` devuelve la dirección de la celda del carácter, por ejemplo `FFE6`.
- `&altura` devuelve la dirección base del número flotante, por ejemplo `FFE2`.
- `&edad[0]` devuelve la dirección de la primera componente del arreglo de enteros, por ejemplo `FFDE`.

Es un error común intentar escribir `&edad` en lugar de `&edad[0]`. Como se estableció previamente, el identificador `edad` por sí solo representa el nombre del arreglo entero (una constante que ya designa la dirección del bloque de memoria) y no es un _l-value_ modificable tradicional. El operador unario `&` requiere aplicarse sobre un _l-value_ concreto, como una celda específica del vector (`&edad[0]` o `&edad[1]`).

Al aplicar el operador `&` sobre un _l-value_ de tipo $X$, la expresión resultante es de tipo puntero a $X$ (`X *`).
```c
char letra = 'P';
float altura = 17.4;
int edad[2] = {25, 12};

char  * pLetra  = &letra;   // Obtiene una expresión de tipo puntero a char
float * pAltura = &altura;  // Obtiene una expresión de tipo puntero a float
int   * pEdad   = &edad[1]; // Obtiene la dirección del segundo elemento (puntero a int)
```

Observando la disposición de las variables en la memoria RAM:
- La variable `letra` guarda la constante ASCII `'P'` en la dirección `FFE6`.
- La variable `altura` almacena el valor `17.4` a partir de la dirección `FFE2`.
- El arreglo `edad` contiene `25` en la dirección `FFDE` (`edad[0]`) y `12` en `FFE0` (`edad[1]`).

Cuando se declaran las variables puntero `pLetra`, `pAltura` y `pEdad`, el sistema les asigna celdas propias en memoria. El valor almacenado dentro de cada una de estas variables puntero es la dirección hexadecimal de la variable a la que apuntan:
- `pLetra` almacena la dirección `FFE6`.
- `pAltura` almacena la dirección `FFE2`.
- `pEdad` almacena la dirección `FFE0` (la dirección del segundo elemento `edad[1]`).

Para imprimir el valor numérico de una dirección de memoria almacenada en un puntero mediante la función `printf`, se utiliza el especificador de conversión **`%p`**.
```c
printf("%p\n", pLetra);
```

El especificador `%p` muestra la dirección de memoria en formato hexadecimal (por ejemplo, `0x7ffcffe6`), adaptando automáticamente la representación a la cantidad de bits de la arquitectura del sistema.

## Operador Unario `*`

El operador unario `*` se aplica sobre una variable de tipo puntero y devuelve el _r-value_ al cual apunta. Se dice que **desreferencia al puntero**, accediendo u obteniendo directamente el valor almacenado en la posición de memoria referenciada.
```c
char letra = 'P', * pLetra = &letra;
float altura = 17.4, * pAltura = &altura;
int edad = 25, * pEdad = &edad;

printf("%c %f %d\n", *pLetra, *pAltura, *pEdad);
```

En este caso, la expresión `*pLetra` accede al valor `'P'`, `*pAltura` devuelve `17.4` y `*pEdad` devuelve `25`.

Un puntero desreferenciado (`*puntero`) actúa exactamente como un _l-value_, lo que permite modificar el contenido de la variable original o utilizarlo en expresiones complejas:
```c
flag = isupper(*pLetra); // Evalúa si el carácter apuntado ('P') es mayúscula (devuelve no cero)
*pEdad = 18;             // Cambia el valor de la variable edad a 18
*pAltura *= 2;           // Equivale a *pAltura = *pAltura * 2 (duplica la altura)
*pLetra = toupper(letra);// Convierte la letra a mayúscula
(*pEdad)++;              // Incrementa en 1 el valor apuntado por pEdad
```

>[!INFO] Precedencia
>El operador de incremento posterior `++` tiene mayor precedencia que el operador unario de desreferenciación `*`. Si se escribiera `*pEdad++`, el operador `++` se aplicaría sobre el puntero `pEdad` (incrementando la dirección de memoria almacenada), en lugar de incrementar el valor entero alojado en la celda. Por ello, los paréntesis `(*pEdad)++` son estrictamente necesarios para forzar la desreferenciación previa e incrementar el contenido acumulado.

Es crítico no confundir la dirección almacenada en el puntero con el dato al cual apunta. Considérese el seguimiento paso a paso del siguiente bloque de código:
```c
int x = -3;
int y = 12;
int *px, *py;

px = &x;
py = &y;
(*px)++;
*py = 50;
*px = *py;
px = py;
(*px)++;
```

1. Al declarar `int *px, *py;`, ambos punteros contienen basura de memoria (`??`), apuntando a direcciones no determinadas.
2. `px = &x;` asigna la dirección de `x` (`FFE2`) al valor derecho de `px`.
3. `py = &y;` asigna la dirección de `y` (`FFE0`) al valor derecho de `py`.
4. `(*px)++;` desreferencia `px` e incrementa la variable `x` de `-3` a `-2`.
5. `*py = 50;` asigna `50` a la variable `y`.
6. `*px = *py;` copia el valor de `y` (`50`) dentro de la variable `x` apuntada por `px`. Ahora `x = 50`.
7. `px = py;` cambia la dirección almacenada en el puntero `px`, haciendo que `px` apunte ahora a la misma dirección que `py` (`FFE0`, la dirección de `y`).
8. `(*px)++;` incrementa el valor apuntado por `px`. Como `px` ahora apunta a `y`, `y` se incrementa de `50` a `51`.

Al finalizar la ejecución:
- La variable `x` contiene `50`.
- La variable `y` contiene `51`.
- Ambos punteros `px` y `py` contienen la dirección `FFE0` (apuntan a la misma variable `y`).

Un error crítico en la programación con punteros es intentar modificar el valor de un puntero que no ha sido inicializado explícitamente con una dirección válida:
```c
int * pInt;
*pInt = 3; // ERROR GRAVE EN TIEMPO DE EJECUCIÓN
```

Al declarar `int * pInt;`, la variable local `pInt` nace con basura de memoria (una dirección completamente aleatoria `??`). Intentar escribir `*pInt = 3;` le ordena al sistema guardar el entero `3` en una dirección desconocida de la memoria RAM. Esto provoca comportamiento indefinido: puede sobrescribir datos críticos de otra variable o, lo más probable, hacer que el sistema operativo aborte de inmediato la ejecución del programa mediante un fallo de segmentación (_Segmentation Fault_). Siempre debe garantizarse que un puntero apunte a una dirección de memoria válida antes de aplicar el operador `*`.

## NULL

Para evitar el problema de desreferenciar punteros sin inicializar o con valor basura, C provee la constante simbólica `NULL`. Definida en cabeceras estándar como `<stdio.h>` y `<stdlib.h>`, `NULL` es un valor especial utilizado para indicar explícitamente que un puntero apunta a "nada" o que contiene una dirección de memoria inválida/no asignada.
```c
#include <stdio.h>

float * pF;
pF = NULL;

if (pF != NULL) {
    printf("Valor apuntado por pF %g\n", *pF);
} else {
    printf("pF es un puntero nulo\n");
}
```

Asignar `NULL` a un puntero al momento de su declaración permite inicializarlo de manera segura. Antes de intentar acceder o modificar el valor apuntado mediante el operador `*`, se debe validar mediante una estructura condicional (`if (pF != NULL)`) que el puntero efectivamente contiene una dirección válida.

Intentar desreferenciar un puntero que vale `NULL` (`*pF` cuando `pF == NULL`) provocará la interrupción inmediata de la ejecución del programa (fallo de segmentación), pero la ventaja de usar `NULL` es que permite al programador verificar el estado del puntero antes de realizar cualquier operación riesgosa.

## Punteros Como Parámetros de una Función

En lenguaje C, las funciones reciben sus parámetros únicamente por valor (copia). Cuando se necesita que una función modifique variables del ámbito que la invoca o devuelva más de un resultado, se recurre al pasaje por referencia indirecta enviando la dirección de memoria de una zona de memoria donde dejar o modificar dicha respuesta.
```c
tipo nombreFunc(tipo * nombreParam, ...);
```

Al llamar a la función, se le debe pasar una dirección de memoria válida, ya sea la dirección de una variable usando el operador unario `&` o una variable que ya sea de tipo puntero:
```c
nombreFunc(&variable);
nombreFunc(variablePunt);
```

Un problema clásico que demuestra la necesidad de punteros en funciones es el intercambio del contenido de dos variables (`swap`), como ya vimos. Pasar los valores directos no funcionaría, ya que la función solo modificaría sus copias locales en la pila (_stack_).
```c
void swap(int *num1, int *num2) {
    int aux;
    
    aux = *num1;
    *num1 = *num2;
    *num2 = aux;
}
```

En la definición, `num1` y `num2` son parámetros de entrada/salida (E/S) de tipo puntero a entero (`int *`). Dentro de la función:
1. Se guarda en una variable auxiliar escalar `aux` el valor apuntado por `num1` (`*num1`).
2. Se copia el valor apuntado por `num2` (`*num2`) en la posición de memoria apuntada por `num1`.
3. Se asigna el valor guardado en `aux` a la posición de memoria apuntada por `num2`.

Para invocar correctamente la función `swap` desde `main`, es obligatorio anteponer el operador de dirección `&` a las variables cuyo contenido se desea intercambiar:
```c
int main(void) {
    int value1 = 2, value2 = 4;
    
    swap(&value1, &value2);
    
    return 0;
}
```

Es de vital importancia recordar los operadores `&` en la invocación. Llamar a la función como `swap(value1, value2)` enviaría los enteros `2` y `4` interpretados como si fuesen direcciones de memoria (las direcciones `0x00000002` y `0x00000004`), lo cual intentará acceder a zonas no autorizadas y provocará un fallo de ejecución inmediato.

Supongamos que en el _stack_ de `main`, `value1` está en la dirección `FFF0` (con valor `2`) y `value2` en la dirección `FFF2` (con valor `4`). Al ejecutar `swap(&value1, &value2)`, se crean en el _stack_ de la función `swap` las variables locales `num1` y `num2`, donde `num1` recibe como contenido la dirección `FFF0` y  `num2` recibe como contenido la dirección `FFF2`. Al desreferenciar dentro de `swap` (`*num1` y `*num2`), la función altera de forma directa el contenido de las posiciones `FFF0` y `FFF2`. Finalizada la ejecución de `swap`, la memoria de `main` queda actualizada con `value1 = 4` y `value2 = 2`.

## Aritmética de Arreglos y Punteros

El lenguaje C permite sumar o restar valores enteros a variables de tipo puntero. Sin embargo, este cálculo no opera como una suma aritmética escalar simple de bytes, sino que se escala según el tamaño del tipo de dato apuntado:
$$p + n \iff p + n \times \text{sizeof}(\text{tipoApuntado})$$

Esta propiedad genera un conjunto de equivalencias directas entre la notación de arreglos y la notación de punteros:
- El nombre de un arreglo `arreglo` representa una constante que equivale a la dirección del primer elemento: `&arreglo[0]`.
- Desreferenciar el nombre del arreglo `*arreglo` equivale a acceder al contenido del primer elemento: `arreglo[0]`.
- Obtener la dirección de una posición específica `&arreglo[i]` equivale a la expresión `arreglo + i`.
- Acceder al valor de una posición específica `arreglo[i]` equivale a la expresión desreferenciada `*(arreglo + i)`.

Si se declara un puntero a flotante `float * pFloat, arreglo[3] = {1.2, 4.8, 3.7};` y se asigna `pFloat = arreglo;`:
- `&arreglo[1]` es equivalente a `pFloat + 1` (avanza `sizeof(float)` bytes en memoria).
- `arreglo[0]` es equivalente a `*pFloat`.
- `arreglo[2]` es equivalente a `*(pFloat + 2)`.

Del mismo modo, los punteros permiten el uso de índices positivos o negativos cuando apuntan a una posición intermedia de un arreglo. Considérese la matriz `int arreglo[2][3] = {{0, 1, 2}, {3, 4, 5}};` asignada a un puntero a entero mediante `pint = arreglo[0];`:
- `*pint = 6;` modifica la primera posición (`arreglo[0][0]`), cambiando `0` por `6`.
- `pint = arreglo[1];` desplaza la dirección contenida en `pint` al inicio de la segunda fila (`&arreglo[1][0]`).
- `*pint = 8;` modifica el primer elemento de esa segunda fila (`arreglo[1][0]`), asignándole `8`.
- `pint[-1] = 7;` retrocede una posición respecto a donde apunta `pint` (accediendo a `arreglo[0][2]`) y le asigna el valor `7`.
- `pint[3] = 0;` intenta acceder 3 posiciones por delante del inicio de la segunda fila (`arreglo[1][3]`), lo que supera los límites de la matriz y accede a memoria fuera del rango asignado.

Sumar o incrementar un puntero solo resulta lógicamente válido cuando la dirección pertenece a una secuencia contigua de elementos (como los elementos de un vector).
- Si se aplica `punt++` sobre una variable escalar aislada `char c = 'Z';`, el puntero pasará a almacenar una dirección adyacente que no contiene un dato definido por el programa (`FFD7`), perdiendo el acceso a una zona de memoria válida.
- Si se aplica `pvec++` sobre un vector de enteros `int vec[] = {1, 3, 0, 7};`, el puntero se desplaza tantos bytes como ocupe el tipo `int` (`sizeof(int)`, habitualmente 4 bytes). Por ende, si `vec` iniciaba en `FFD6`, el incremento `pvec++` ajusta la dirección a `FFD8`, logrando que `pvec` apunte de forma segura y precisa al segundo elemento del vector (`3`).

Para determinar si un valor `num` pertenece a un vector de enteros `v`, se puede implementar la solución en notación tradicional de arreglos utilizando un bucle `for` condicionado:
```c
int belongs(const int v[], int num, unsigned int dim) {
    int exist = 0;
    
    for (int i = 0; i < dim && !exist; i++) {
        exist = (v[i] == num);
    }
    
    return exist;
}
```

En esta función, la expresión `v[i]` se evalúa internamente como `*(v + i)`. El uso de `const` en la firma de la función protege los elementos del vector contra modificaciones accidentales dentro del cuerpo de la función.

## Operaciones Aritméticas Válidas

Dentro de la aritmética de punteros en C, no todas las operaciones matemáticas convencionales están permitidas. Existen reglas estrictas sobre el incremento, decremento, diferencia y suma entre punteros.

Aplicar el **operador de incremento** (`puntero++` o `++puntero`) sobre un puntero desplaza la dirección de memoria apuntada hacia adelante. El cálculo exacto de la nueva dirección se ajusta según el tamaño en bytes del tipo de dato apuntado:
$$\text{puntero} = \text{puntero} + 1 \times \text{sizeof}(\text{tipo})$$

Si un puntero a entero (`sizeof(int) = 4`) contiene la dirección `FFC0`, realizar `puntero++` moverá la dirección "4 lugares" más adelante, resultando en la nueva dirección `FFC4`.

De forma análoga al incremento, el **decremento** (`puntero--` o `--puntero`) desplaza la dirección de memoria hacia atrás, restando el tamaño del tipo de dato apuntado:
$$\text{puntero} = \text{puntero} - 1 \times \text{sizeof}(\text{tipo})$$

Si un puntero de tipo de 4 bytes se encuentra en la dirección `FFC4`, al ejecutar `puntero--` la dirección retrocede 4 bytes, retornando a `FFC0`.

**Restar dos punteros** (`puntero1 - puntero2`) del mismo tipo es una operación válida y ampliamente utilizada para medir la distancia o cantidad de elementos entre dos posiciones dentro de una misma estructura de memoria (como un vector):
$$\text{distancia} = \frac{\text{puntero1} - \text{puntero2}}{\text{sizeof}(\text{tipo})}$$

El resultado de restar dos punteros no devuelve una cantidad de bytes, sino un número entero (de tipo `ptrdiff_t`) que indica cuántos elementos hay entre ambas direcciones:
- Si `puntero1` apunta a la dirección `FFCC` y `puntero2` apunta a `FFC0` (con un tamaño de tipo de 4 bytes), la resta `puntero1 - puntero2` se evalúa como `(FFCC - FFC0) / 4`, lo que equivale a `12 / 4 = 3` elementos de distancia.
- Si la operación se realiza en orden inverso (`puntero2 - puntero1`), el resultado será un entero negativo (`-3`), indicando que `puntero2` se encuentra posicionado antes que `puntero1` en la memoria (`puntero2 - puntero1 < 0`).

Sumar dos direcciones de memoria (`puntero1 + puntero2`) **NO es una operación válida en C y no compila**. Conceptualmente, sumar dos direcciones de memoria carece de sentido físico dentro del mapa de memoria de un programa, por lo que el compilador genera un error de sintaxis si se intenta realizar.

## Operaciones de Asignación

Además de las operaciones de incremento, decremento y resta, en C se pueden aplicar operadores de asignación combinada sobre punteros para desplazarlos una cantidad fija de posiciones:
- **Asignación con suma (`puntero1 += numero`):** Desplaza la dirección de memoria hacia adelante en `numero` cantidad de elementos de tipo `sizeof(tipo)`. Equivale a la expresión `puntero1 = puntero1 + numero`.
- **Asignación con resta (`puntero1 -= numero`):** Desplaza la dirección de memoria hacia atrás en `numero` cantidad de elementos de tipo `sizeof(tipo)`. Equivale a la expresión `puntero1 = puntero1 - numero`.
- **Asignación de puntero a puntero (`puntero1 = puntero2`):** Copia directamente la dirección almacenada en `puntero2` dentro de `puntero1`, haciendo que ambos punteros apunten al mismo bloque de memoria.

En el estándar **ANSI C**, los punteros tienen tipos estrictos basados en el tipo de dato al que apuntan. Por esta razón, la asignación directa entre punteros de distinto tipo no está permitida sin un _cast_ explícito:
$$\text{char *} \neq \text{int *} \neq \text{float *}$$

## Operaciones de Comparación

En lenguaje C es posible utilizar operadores relacionales e de igualdad para comparar dos direcciones de memoria. Las operaciones de comparación válidas entre punteros son:
- **Igualdad y desigualdad** (`puntero1 == puntero2`, `puntero1 != puntero2`): Permiten verificar si dos punteros apuntan exactamente a la misma posición de memoria o si están apuntando a direcciones distintas.
- **Comparaciones relacionales** (`puntero1 < puntero2`, `puntero1 <= puntero2`, `puntero1 > puntero2`, `puntero1 >= puntero2`): Permiten determinar qué dirección de memoria se encuentra antes o después de la otra. Internamente, el compilador traduce estas comparaciones relacionales a una resta de punteros (`puntero1 - puntero2`), verificando si el resultado de la distancia es mayor, menor o igual a cero. Para que las comparaciones relacionales tengan sentido lógico, ambos punteros deben apuntar a elementos de una misma estructura continua en memoria (como un arreglo).

Una de las aplicaciones más frecuentes de las comparaciones de igualdad es verificar si un puntero ha sido inicializado o si apunta a una dirección de memoria válida.
- `puntero == NULL`: Evalúa si el puntero es un puntero nulo (no apunta a ninguna zona de memoria asignada). Es fundamental para evitar desreferenciar un puntero antes de haberle asignado memoria.
- `puntero != NULL`: Verifica que el puntero contiene una dirección válida antes de intentar acceder o modificar su contenido mediante el operador de desreferenciación `*`.

A nivel funcional, es posible resolver un mismo problema utilizando notación de arreglos con índices o notación de punteros con aritmética de direcciones. Sin embargo, no siempre ambas soluciones ofrecen la misma legibilidad o siguen la misma estrategia de ejecución.
```c
for (i = 0; i < n; i++)
    dest[i] = source[i];
```

En esta variante se realiza el copiado convencional desde el primer elemento (índice `0`) hasta el elemento `n - 1`.

Mediante punteros:
```c
for (p = dest + n, s = source + n; p > dest; )
    *--p = *--s;
```

Ambos fragmentos de código producen un resultado equivalente en el arreglo destino, pero no operan de la misma forma:
- La expresión `p = dest + n` inicializa el puntero posicionándolo una posición por delante del último elemento del vector (`último + 1`).
- En la condición del bucle se utiliza la comparación relacional `p > dest` para detener el recorrido apenas el puntero alcance la dirección base de `dest`.
- Dentro de la iteración, los operadores de pre-decremento `*--p = *--s;` primero retroceden ambos punteros un elemento (apuntando al elemento válido) y luego realizan la asignación del valor. Este enfoque recorre el vector en sentido inverso, desde el último elemento hasta el primero.
