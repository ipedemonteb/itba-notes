## Funcionamiento

A nivel de hardware, cuando el programa usa una variable, la máquina va a una dirección de memoria específica y trae el valor almacenado allí. En lenguaje de bajo nivel (Assembly), esto se traduce en instrucciones de carga referenciando a un registro o etiqueta de memoria (ej. `LD (), (b)`) en lugar de cargar un valor constante directo (ej. `LD (), 100`). Como la variable reside en una zona de memoria dinámica, su contenido puede cambiar a lo largo de la ejecución.

Toda variable posee cuatro atributos fundamentales:
- **Nombre (Identificador):** Es el texto que usamos para referenciarla. No puede haber otra variable con el mismo nombre dentro del mismo ámbito.
- **Tipo:** Determina qué clase de datos almacena (ej. `int`, `float`, `char`). Su tipo es estricto y no puede cambiar una vez declarada.
- **Valor Izquierdo (_L-value_):** Es la dirección de memoria física donde está guardada la variable.
- **Valor Derecho (_R-value_):** Es el contenido o valor asignado que reside dentro de esa dirección de memoria.

Si tenemos una variable en el código con la dirección 1000 y almacena el número 21:
- Valor Izquierdo (L-value): 1000 (la celda de memoria)
- Valor Derecho (R-value): 21 (lo que está adentro)

Un **identificador** es simplemente el nombre tokenizado que utiliza el compilador para reconocer los distintos elementos del programa, ya sean variables o funciones del sistema como `main` y `printf`. Al trabajar con ellos, una regla fundamental en C es que el lenguaje es estrictamente sensible a las mayúsculas y minúsculas (_case sensitive_); por lo tanto, nombres como `Cantidad` y `cantidad` serán interpretados por el compilador como dos variables completamente diferentes. 

Cuando usamos nombres compuestos, lo ideal es adoptar estilos estandarizados como **camel case** (por ejemplo, `diaDelMes`) o **snake case** (como `mayor_valor`). Sin importar cuál elijamos, las variables deben tener siempre un nombre significativo que describa con claridad qué datos almacenan, evitando por completo letras genéricas como `v1` o `v2`. Finalmente, aunque en el ámbito profesional el estándar de la industria es programar los identificadores en inglés, si decidimos estructurar las notas y el código en español, debemos mantener una consistencia absoluta en todo el archivo fuente.

>[!INFO] Reglas:
>- Los identificadores no deben tener underscore ni al comienzo ni al final.
>- Evitar tener identificadores que sólo difieran en una letra, por ser mayúscula en uno y minúscula en otro.
>- Evitar identificadores que se parezcan mucho entre sí.
>- Evitar usar la 1 (letra ele) y el 1 (uno).
>- Evitar usar nombres de la biblioteca estándar.

Para poder usar una variable, la misma debe ser declarada previamente.
```C
// Definir:
tipo nombre1, nombre2;

// Definir e Inicializar:
tipo nombre1 = valorInicial;
```
En el primer caso, se define únicamente la variable porque no se hace más que asignarle un espacio. En cambio, en la segunda opción se inicializa porque además se le asigna un valor.

Algunos casos:
```c
int cantidad, acumulador = 0, edad;
float sueldo;
char letra = 'M';
float delta = 0.001F;
enum dias_habiles diaDePago;
enum meses mes = JUN;
```
En el caso de `dias_habiles`, es lo mismo usar el `enum` que un `int`, pero uso el primero para que el usuario tenga claro qué valores debería tomar.

Tomemos el siguiente ejemplo:
```c
int mult(int n, int m) {
	return n * m;
}

int main(void) {
	double x;
	x = mult(1.5, 3);
	return 0;
}
```
Luego de ejecutar la función, el valor final de `x` será `3.0` y no `4.5`. Esto ocurre porque en el prototipo de la función `mult` se especificó que recibiría un parámetro de tipo `int`. Al pasarle el valor `1.5`, el sistema lo trunca y lo interpreta directamente como `1`, por lo que la operación interna se resuelve como `1 * 3`. La función termina devolviendo el entero `3` pero, como establecimos que la variable de destino `x` es un `double`, este resultado se convierte finalmente en `3.0`.

El clasificador `const` se utiliza para indicarle al compilador que el contenido de una variable determinada es de solo lectura y no debe ser alterado por el programa durante su ejecución. Cabe aclarar que es una herramienta que no vamos a utilizar por el momento en el curso.
```c
const tipo nombre = valorInicial;
```

## Definición de Alias

La palabra clave `typedef` nos permite crear un alias o un sinónimo para un tipo de dato ya existente en el lenguaje. Es importante destacar que no estamos creando un tipo de dato nuevo desde cero, sino simplemente dándole un nombre alternativo para mejorar la abstracción, legibilidad o mantenibilidad del código.
```c
typedef tipoDeDato alias;
```

Por ejemplo, si escribimos la línea `int entero;`, estamos declarando una variable convencional. Sin embargo, si le anteponemos la palabra clave para transformarlo en `typedef int entero;`, lo que estamos haciendo es definir la palabra `entero` como un alias válido para `int`. A partir de ese momento, podemos declarar variables escribiendo directamente `entero dividendo, divisor;`, lo cual para el compilador es exactamente equivalente a haber tipeado `int dividendo, divisor;`. Esto abre la posibilidad, entre otras cosas, de adaptar la nomenclatura de los tipos al idioma en el que estemos documentando el desarrollo.

Un uso fundamental del `typedef` es facilitar modificaciones estructurales en el software de forma centralizada. Imaginemos que definimos un alias para manejar edades en nuestro programa mediante la instrucción:
```c
typedef short tipoEdad;
```

A lo largo de todo el código fuente, en lugar de utilizar el tipo primitivo `short`, declaramos las variables usando nuestro alias `tipoEdad`. Si el día de mañana los requerimientos del sistema cambian drásticamente (por ejemplo, si la expectativa de vida aumentara tanto que el rango de un `short` ya no fuera suficiente para almacenar una edad), no tendríamos la necesidad de rastrear y modificar manualmente cada declaración del programa. Nos bastaría con actualizar la línea del alias a `typedef int tipoEdad;` para que el cambio se replique automáticamente en todo el sistema.

El uso de `typedef` se vuelve también sumamente práctico al trabajar con tipos compuestos, como las enumeraciones (`enum`), ya que nos permite omitir la necesidad de repetir la palabra clave `enum` en cada declaración. Podemos ver su evolución en el diseño de una función:
```c
// Opción 1: Sin enumeración (Poco descriptivo)
int primerDia(int mes, int anio);

// Opción 2: Con enumeración pero sin alias (Sintaxis pesada)
enum dias { LUN, MAR, MIE, JUE, VIE, SAB, DOM };
enum dias primerDia(int mes, int anio);

// Opción 3: Modularizado elegantemente con typedef
enum dias { LUN, MAR, MIE, JUE, VIE, SAB, DOM };
typedef enum dias tipoDia;

tipoDia primerDia(int mes, int anio); // Retorna un dato de tipoDia de forma limpia
```

Dado que las versiones clásicas de C no incorporan de forma nativa un tipo de dato booleano, el uso combinado de `typedef` y `enum` es el estándar clásico para construirlo manualmente dentro de la lógica del programa:
```c
// Combinamos la definición del enum y el alias bool en una sola línea:
typedef enum { false = 0, true } bool;

int main(void) {
    bool exist = false;
    bool ok = true;
    
    // ... lógica del programa ...
    
    return 0;
}
```

## Caracteres

En el desarrollo de esta materia, se establece como regla estricta que **NO vamos a usar caracteres en español** (como la ñ, vocales con tildes o diéresis).
- **Restricción del curso:** Únicamente utilizaremos caracteres cuyo valor en la tabla ASCII estándar se encuentre estrictamente en el rango de **0 a 127**.
- **Manejo de ASCII Extendido:** Para poder procesar correctamente caracteres de otros idiomas o del formato ASCII extendido (que requieren más de un byte), el lenguaje obliga a recurrir a herramientas específicas como la directiva `#include <wchar.h>`, el tipo de dato `wchar_t`, el sufijo `L` para los literales (ej. `L'ñ'`) y la configuración de la localización mediante `<locale.h>`.

## Entrada de Datos

La función `getchar()` se utiliza para leer el siguiente carácter disponible en la entrada estándar (el buffer del teclado). Su sintaxis de invocación es simplemente `getchar()`, y devuelve el carácter leído como un `unsigned char` convertido automáticamente a `int`. Esto garantiza que siempre devuelva un valor entero en el rango de 0 a 255.

Para saber cuándo finaliza la entrada de datos o si ocurrió un error, la función devuelve la constante simbólica **`EOF`** (`getchar() == EOF`). Como los caracteres válidos ocupan el rango `[0, 255]`, ANSI C indica que `EOF` debe ser un número negativo para no confundirse con ningún carácter. En el archivo de cabecera `<stdio.h>`, está definido textualmente como `#define EOF -1`.

Cuando escribimos en la terminal, los caracteres (incluyendo el _Enter_ o salto de línea) se guardan secuencialmente en el buffer del teclado. Cada llamada a `getchar()` toma el primer carácter disponible de esa fila. Tomemos el siguiente fragmento:
```c
int c1, c2, c3;
c1 = getchar();
c2 = getchar();
c3 = getchar();
```

Para la entrada `A3CD↵` el buffer recibe los caracteres: `'A'`, `'3'`, `'C'`, `'D'` y la tecla _Enter_ (`'\n'`). 
- `c1` toma el primer elemento: el ASCII de `'A'` (en hexadecimal: `41`).
- `c2` toma el segundo: el ASCII de `'3'` (en hexadecimal: `33`).
- `c3` toma el tercero: el ASCII de `'C'` (en hexadecimal: `43`)
 
> [!Info] Nota
> El carácter `'D'` y el _Enter_ (`'\n'`) quedan guardados en el buffer fuera de estas variables, listos para los próximos `getchar()`.

El **redireccionamiento** nos permite cambiar el origen desde donde la función `getchar()` lee los datos. En lugar de esperar que el usuario escriba en el teclado, podemos indicarle al sistema operativo que tome el contenido de un archivo de texto como entrada del programa. La sintaxis es:
```bash
./a.out < xx.txt
```

Si el archivo `xx.txt` contiene únicamente los caracteres `1` y `2`, las dos primeras llamadas a `getchar()` leerán esos valores. En la tercera llamada (`c3`), al no haber más contenido, la función se topa con el final del archivo y almacena la constante `EOF` (cuyo valor es siempre `-1`). Si el código sigue ejecutando más llamadas a `getchar()` (`c4`, `c5`, etc.), todas continuarán devolviendo el valor de `EOF` de manera indefinida.

Cuando queremos determinar en una variable (por ejemplo, `final`) si el carácter leído corresponde al fin de archivo, existen diferentes formas de estructurar la asignación. El uso de operadores condicionales complejos puede oscurecer la lectura del código de forma innecesaria. Para entender este caso es necesario leer la unidad de [[04. Operadores|operadores]].
```c
// Opción 1: Semántica confusa (Operador ternario innecesario)
int final, c;
final = (((c = getchar()) != EOF) ? 0 : 1);

// Opción 2: Semantics limpia y recomendada
int final, c;
final = ((c = getchar()) == EOF);
```

En la primera opción, la lógica se vuelve enredada al usar un operador ternario para asignar `0` si es distinto o `1` si es igual. La segunda opción es mucho más limpia y directa: como los operadores relacionales (como `==`) devuelven por sí mismos un entero `0` (Falso) o `1` (Verdadero), la variable `final` guardará automáticamente un `1` si se llegó al fin de archivo, o un `0` si el carácter leído es válido.

## Salida de Datos

Para enviar información a la **salida estándar** (la consola), el lenguaje provee funciones específicas en la biblioteca `<stdio.h>`.  La función `putchar()` es una función unaria diseñada exclusivamente para imprimir un único carácter en la consola. Su sintaxis recibe un entero o carácter:
```c
putchar(valorASCII);

putchar('P');   // Imprime la letra 'P'
putchar(65);    // Imprime la letra 'A' (65 es el código ASCII de la 'A')
putchar('\n');  // Realiza un salto de línea
putchar('x');   // Imprime la letra 'x'

// Salida en consola:
// PA
// x
```

La función `printf()` permite imprimir cadenas de texto formateadas mediante el uso de especificadores de formato (como `%d`, `%f`, `%c`, etc.). Al invocar funciones que aceptan una cantidad variable de argumentos (como `printf`), los tipos de datos más pequeños sufren una promoción automática antes de ser procesados por la función:
- Los tipos enteros cortos (`char` y `short`) se promueven automáticamente a `int`.
- El tipo de punto flotante simple (`float`) se promueve automáticamente a `double`.

```c
char a;    // Se pasa a la función promovido como (int)a
short b;   // Se pasa a la función promovido como (int)b
int c;     // Se mantiene como int
float x;   // Se pasa a la función promovido como (double)x

printf("%d %c %x %f %g\n", a, b, c, x, x);
```

A través de los **modificadores de formato**, podemos controlar con precisión cuántos caracteres y decimales queremos mostrar en la pantalla. Se colocan entre el símbolo `%` y la letra de conversión para alterar el comportamiento por defecto de la salida.

|        **Símbolo**         |                                                                                  **Significado y Conversión**                                                                                   |
| :------------------------: | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|            `-`             |                                        Alineamiento a la izquierda: Por defecto, los campos se alinean a la derecha. Este signo cambia la justificación.                                        |
|            `0`             |                                       Rellena con ceros: En lugar de completar con espacios en blanco los campos vacíos, los rellena con el carácter `0`.                                       |
|   _Un número_<br>(Ancho)   |                            Ancho mínimo de campo: Imprime un campo de al menos el ancho indicado, completado con blancos a la izquierda o derecha según corresponda.                            |
|            `*`             |                                   El ancho o la precisión no se fijan en la cadena de formato, sino que se toman directamente de un argumento de la función.                                    |
|            `.`             |                                                       Separador: Separa el ancho de la parte entera de lo que corresponde a la precisión.                                                       |
|            `+`             |                                                   Fuerza el signo: Imprime siempre el signo numérico, incluso si el valor es positivo (`+`).                                                    |
| _Un número_<br>(Precisión) | Para punto flotante (`%f`): Número de dígitos decimales a mostrar.<br>Para cadenas (`%s`): Número máximo de caracteres a imprimir.<br>Para enteros (`%d`): Número mínimo de dígitos a imprimir. |
>[!TIP] Modificadores de Tamaño (Tipado)
>- `h`: Para tipos `short` (ej: `%hd`).
>- `l`: Para tipos `long` (ej: `%ld` o `%lc`).
>- `L`: Para tipos `long double` (ej: `%Lf`).

Tomemos el siguiente caso, donde el asterisco (`*`) se colocó de forma literal para marcar visualmente dónde termina el espacio reservado por el modificador.
```c
printf("num vale %f*\n", num);
// Imprime: num vale 18.490000* (por defecto, %f muestra 6 dígitos decimales)

printf("num vale %5.2f*\n", num);
// Imprime: num vale 18.49*

printf("num vale %5.1f*\n", num);
// Imprime: num vale  18.5*

printf("num vale %-5.1f*\n", num);
// Imprime: num vale 18.5 * (El signo menos '-' justifica a la izquierda; el espacio de relleno se agrega a la derecha)

printf("num vale %5.0f*\n", num);
// Imprime: num vale    18* (Reserva 5 espacios con 0 decimales. Rellena con 3 espacios a la izquierda)

printf("num vale %d*\n", num);
// Imprime: num vale 2* (o puede dar 0 según el compilador). ERROR TÉCNICO: Se utiliza %d (especificador para enteros) pero se le pasa un float. 
```

Utilizando el mismo valor entero, podemos visualizarlo en diferentes formatos de salida según el especificador elegido:
```c
int a = 49;
float b = 3.5;

printf("a vale %d\n", a);
// Imprime: a vale 49

printf("Corresponde al caracter %c\n", a);
// Imprime: Corresponde al caracter 1
// (Muestra el carácter asociado al código ASCII 49, que es el número '1')

printf("En hexa %x, en octal %o\n", a, a);
// Imprime: En hexa 31, en octal 61
// (%x muestra el valor en base hexadecimal y %o en base octal)

printf("b vale %f\n", b);
// Imprime: b vale 3.500000
```

Para lograr una impresión alineada en columnas con datos de estados, área, forestación y porcentaje, se utiliza la siguiente estructura fija:
```c
printf("%-14.14s\t%6d\t%6d\t%4.1f%%\n", "Alabama", 50750, 33945, 33945.0/50750*100);
```

Los modificadores usados son:
- `%-14.14s` (Columna de Estado):
    - `-`: Justifica el nombre del estado a la izquierda.
    - `14` (Ancho): Reserva un espacio mínimo de 14 caracteres en pantalla. Si el nombre es más corto, mete espacios a la derecha.
    - `.14` (Precisión): Establece que, si un nombre llegara a superar los 14 caracteres, se trunca exactamente en el carácter 14 para no deformar la tabla.
- `\t`: Inserta un tabulador horizontal para separar físicamente las columnas.
- `%6d` (Columnas de Área y Forestación):
    - Reserva un ancho fijo de 6 caracteres para los enteros, alineándolos a la derecha de manera natural para que coincidan las unidades.
- `%4.1f%%` (Columna de Porcentaje):
    - `4.1f`: Reserva un ancho total de 4 caracteres (contando el número, el punto y el decimal) y fija exactamente 1 dígito decimal.
    - `%%`: Es la forma de escapar el símbolo de porcentaje para que se imprima de forma literal (`%`) al final del número en la consola.

La función `puts()` se utiliza para enviar una cadena de caracteres (_string_) directamente a la salida estándar. A diferencia de otras funciones de salida, añade automáticamente un carácter de salto de línea (`'\n'`) al final de la cadena impresa en la consola. Las siguientes cuatro instrucciones son completamente equivalentes y producen exactamente el mismo resultado visual en la pantalla:
```c
puts("Hello, world!");
printf("Hello, world!\n");
printf("%s", "Hello, world!\n");
printf("%s\n", "Hello, world!");
```

A pesar de que las cuatro opciones logran el mismo objetivo, `puts()` es la alternativa más rápida y eficiente en cuanto a rendimiento. La función `printf()` es un motor de formateo complejo. Cada vez que se ejecuta, el programa tiene que escanear la cadena de texto carácter por carácter buscando activamente el símbolo `%` para evaluar si existen especificadores de tipo (como `%d`, `%g`, `%s`, etc.). En cambio, `puts()` no busca modificadores ni formatea nada; simplemente agarra el bloque de texto completo, lo vuelca en la consola y le pega el `\n` al final, ahorrando ciclos de procesamiento.
