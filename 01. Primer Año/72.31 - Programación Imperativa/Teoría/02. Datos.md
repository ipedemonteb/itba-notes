## Preprocesador

El preprocesador actúa en una etapa previa a la compilación propiamente dicha. Su primera tarea es encargarse de eliminar la totalidad de los comentarios del código fuente. Además, se ocupa de resolver las directivas `#include`, insertando el contenido de los archivos indicados exactamente en el lugar donde fueron invocados, como si los hubiésemos escrito nosotros mismos de forma manual; debido a esto, el compilador procesa un único bloque de texto continuo y no tiene forma de distinguir si el código fue tipeado directamente en el archivo o si proviene de una inclusión externa. 

La forma en que escribimos estas directivas le indica al preprocesador dónde debe buscar: si el nombre del archivo se coloca entre comillas dobles `""`, se buscará primero en el directorio local o entorno en el que estamos trabajando; en cambio, si se coloca entre signos de menor y mayor `<>`, la búsqueda se realizará directamente en los directorios del sistema preconfigurados por el compilador.
```c
// En un directorio especial
#include <nombreDeArchivo>

// En el directorio actual de trabajo
#include "nombreDeArchivo"
```

>[!info] Estandarización de Estilo:
Nos va a ayudar en la claridad, portabilidad y mantenibilidad de un código, así como reducir la probabilidad de cometer errores. Es importante que un grupo de programadores adopten reglas comunes y claras de estilo.

## Tipos de Datos

El **tipo de un dato** determina de forma estricta el conjunto de valores que este puede adoptar y las operaciones válidas que se pueden realizar sobre él. Una característica clave de *C* es que maneja los tipos de datos de manera muy cercana a como lo hace el hardware de la computadora. Si declaramos una variable de tipo entero, no vamos a poder asignarle más bytes de los que permite almacenar un entero en los registros de nuestro procesador; lo mismo ocurre con los tipos flotantes y el coprocesador matemático o microprocesador. 

Al depender tan directamente de la arquitectura física de la máquina, este comportamiento puede provocar problemas de portabilidad, haciendo que un mismo programa compile y corra perfectamente en una computadora pero falle o se comporte distinto en otra. Para conocer los rangos exactos y las especificaciones de hardware de cada tipo de dato en un sistema en particular, se pueden consultar las constantes definidas en la librería `limits.h`.

Dentro de los números enteros, el tipo más básico es `char`, que representa un carácter y ocupa exactamente 1 Byte (8 bits). Este puede ser `unsigned char`, con un rango de 0 a 255, o `signed char`, cuyo rango va de -128 a 127 utilizando representación en complemento a la base; cabe destacar que para el `char` no existe un signo por defecto en el estándar, por lo que depende de la implementación. 

>[!info] Representación de Letras
> Las letras no existen en el procesador, en la memoria sólo hay bytes. Cuando queremos guardar una letra, usamos una convención donde un número representa la “a”. 

Por otro lado, el tamaño de un `int` depende directamente de la palabra de la máquina, ocupando usualmente 2 o 4 Bytes. Si la arquitectura es de 2 Bytes (16 bits), el `unsigned int` va de 0 a 65535, mientras que el `signed int` va de -32768 a 32767, siendo este último el comportamiento por defecto (_default_). Según el estándar *ANSI C*, se debe garantizar la jerarquía de tamaños donde 16 bits sea menor o igual al tamaño de un `short int`, este menor o igual a un `int`, y este menor o igual a un `long int`, asegurando que el `long int` sea como mínimo de 32 bits.

En algunos casos, incluso podemos omitir el `int`.
```c
// Equivalencias válidas omitiendo el 'int':
short x;         // Equivale a: short int / signed short int
long y;          // Equivale a: long int / signed long int
unsigned short z;// Equivale a: unsigned short int
unsigned long w; // Equivale a: unsigned long int
```

>[!info] Booleanos
>En C, no tenemos valores booleanos, es decir que no existen el true y false. Se usa el 0 para representar el falso y cualquier otro número para representar el verdadero. Lo guardamos en un entero.

En cuanto a los números decimales, el tipo `float` permite almacenar valores en punto flotante de precisión normal bajo el formato IEEE-754, mientras que el tipo `double` permite almacenar, dependiendo de la plataforma, valores en punto flotante de doble precisión bajo el mismo formato estándar.

>[!QUOTE] Según el *ANSI C*:
> `float`$\leq$`double`$\leq$`long double`

A la hora de escribir código, podemos definir variables de la siguiente forma: 
```c
int x = 2;
char y = x;
double a = 1.55;
```

> [!TIP] Casting
Si necesitamos forzar la conversión de un tipo a otro, podemos realizar un _casting_ utilizando la sintaxis `(tipo de dato) valor`. De esta manera, explicitamos el tipo de dato de un valor o una expresión de forma directa sin la necesidad de definir una variable intermedia.

Por último, vale la pena recordar que la interpretación de estos datos afecta también al flujo del sistema: cuando la función `main` retorna un 0, la terminal (como Bash) interpretará que el programa terminó correctamente, mientras que cualquier valor distinto de cero será tomado como una finalización con errores.

## Constantes

El único atributo que posee una **constante** es su valor, el cual debe pertenecer obligatoriamente al dominio de alguno de los tipos de datos soportados por el lenguaje y tiene la condición estricta de no poder modificarse en ningún momento durante la ejecución del programa. 

A la hora de escribir constantes numéricas en el código, la forma en que las anotamos le indica al compilador la base que estamos utilizando. Por ejemplo, si vemos un cero delante de un número, como en `021`, esto nos indica que el valor está representado en sistema octal; por otro lado, el prefijo `0x` delante de una cifra, como en `0x11`, se utiliza para indicar que el número está expresado en sistema hexadecimal.

Cuando declaramos una constante numérica literal en el código, el compilador debe asignarle un tipo de dato de forma automática. Para hacerlo, sigue un orden de prioridad estricto (de arriba hacia abajo) según el tamaño que ocupe el valor.
- Para constantes decimales:
	1. `int`
	2. `long`
	3. `unsigned long`
- Para constantes octales o hexadecimales:
	1. `int`
	2. `unsigned int`
	3. `long`
	4. `unsigned long`

>[!TIP] Sufijos Para Enteros
>Si queremos alterar este comportamiento predeterminado, podemos usar sufijos al final del número para indicarle explícitamente el tipo al compilador:
>- `u` o `U`: Fuerza a que el valor sea `unsigned`.
>- `l` o `L`: Fuerza a que el valor sea `long`.
>
>_Tip de estilo:_ Se pueden usar mayúsculas o minúsculas, pero la `L` siempre conviene usarla en mayúscula para evitar que se confunda visualmente con el número `1`.

Podemos ver cómo cambia la interpretación de un mismo valor según los sufijos aplicados:
```c
135     // El compilador lo asume como: signed int
135L    // Forzado a: signed long
135U    // Forzado a: unsigned int
135UL   // Forzado a: unsigned long
```

En C, las constantes de carácter (las que van entre comillas simples) son de tipo `int`, NO de tipo `char`. El compilador las interpreta directamente por su valor numérico en la tabla *ASCII*. Por ejemplo, escribir `'A'` es exactamente lo mismo que escribir el entero `65`.

Para representar caracteres especiales que no se pueden tipear directamente (como comillas, tabulaciones o saltos de línea), utilizamos **secuencias de escape** anteponiendo una barra invertida (`\`):

| **Secuencia** |     **Significado**     |                          **Descripción**                          |
| :-----------: | :---------------------: | :---------------------------------------------------------------: |
|     `\n`      |       Nueva línea       |        Mueve el cursor al principio de la siguiente línea         |
|     `\t`      |  Tabulación horizontal  |        Desplaza el cursor al siguiente tope de tabulación         |
|     `\v`      |   Tabulación vertical   |                 Desplaza el cursor verticalmente                  |
|     `\b`      | Retroceso (_Backspace_) |              Mueve el cursor un espacio hacia atrás               |
|     `\r`      |    Retorno de carro     |           Mueve el cursor al inicio de la línea actual            |
|     `\f`      | Alimentación de página  |            Salto de página en impresoras (_Form Feed_)            |
|     `\a`      |    Alerta o campana     |          Emite un sonido de alerta del sistema (_Beep_)           |
|     `\\`      |     Barra invertida     |                 Permite imprimir el carácter `\`                  |
|     `\'`      |     Comilla simple      | Permite representar la comilla simple `'` sin cerrar la constante |
|     `\"`      |      Comilla doble      |      Permite incluir comillas dobles `"` dentro de un string      |
|     `\?`      | Signo de interrogación  |     Evita interpretaciones ambiguas en secuencias específicas     |

>[!TIP] Sufijos Para Decimales
>  Si escribimos un número con decimales, el compilador lo asume automáticamente como tipo `double`. Si queremos modificar este tipo asumido, debemos usar sufijos:
>  - Sufijo `f` o `F`: Fuerza a que sea `float` (Ej: `1.7F`).
>  - Sufijo `l` o `L`: Fuerza a que sea `long double` (Ej: `16.3L`).

>[!CAUTION] Uso de Comillas
>En C, la comilla simple y la comilla doble no son intercambiables:
>- `'a'`: Es una constante de carácter (ocupa espacio de un entero en el compilador).
>- `"a"`: Es una cadena de caracteres. Almacena la letra `a` y automáticamente agrega el carácter nulo `\0` al final para marcar el cierre de la cadena en memoria.

El tamaño de una cadena siempre es igual a la cantidad de caracteres visibles **más 1 byte extra** correspondiente al terminador `\0`. Podemos analizar los siguientes casos:

| **Constante Cadena** | **Tamaño (Bytes)** |                                                                 **Explicación / Comportamiento**                                                                 |
| :------------------: | :----------------: | :--------------------------------------------------------------------------------------------------------------------------------------------------------------: |
|         `""`         |         1          |                                                               Cadena vacía. Solo contiene el `\0`.                                                               |
|       `"Juan"`       |         5          |                                                          4 caracteres de las letras + 1 byte del `\0`.                                                           |
|     `" 'Juan' "`     |         7          |                                                   Incluye los dos caracteres de comillas simples en el conteo.                                                   |
|     `"\"Juan\""`     |         7          |                                                 Usa secuencias de escape para incluir comillas dobles legibles.                                                  |
|        `"\\"`        |         2          |                                                      Representa una única barra invertida (`\`) + el `\0`.                                                       |
|    `"Juan Perez"`    |         11         |                                                       El espacio en blanco cuenta como un carácter válido.                                                       |
|       `"Caño"`       |       5 ó 6        | El tamaño de la `ñ` y caracteres especiales depende de la codificación del compilador (ej. UTF-8 usa 2 bytes). _Nota: En el curso no usaremos estos caracteres._ |
|     `"uno""dos"`     |         7          |             **Concatenación automática:** Cuando hay dos cadenas seguidas sin operadores, el compilador las une en `"unodos"` (6 caracteres + `\0`).             |

Utilizamos las **enumeraciones** cuando necesitamos asociar un nombre identificable con un valor numérico entero. Su principal objetivo es agrupar una lista de constantes relacionadas bajo un mismo contexto (por ejemplo, los días de la semana o estados de un proceso).

>[!WARNING] Desventaja Principal 
>El tipo `enum` trabaja **únicamente con valores enteros**. No se pueden utilizar para agrupar flotantes u otros tipos de datos complejos.

La sintaxis general para definir una enumeración es:
```c
enum nombre_de_la_enumeracion {LISTA_DE_CONSTANTES};
```

Si no se inicializa explícitamente ningún elemento, el estándar de C le asigna automáticamente el valor `0` al primero de la lista. A partir de ahí, cada constante subsiguiente adopta un valor equivalente al anterior incrementado en 1 (`anterior + 1`). 

Podemos forzar el valor de cualquier constante usando el operador `=`. Si solo le asignamos un valor al primer elemento, los siguientes continuarán la secuencia sumando de a uno de forma automática.
```c
enum dias { LUNES = 0, MARTES, MIERCOLES, JUEVES, VIERNES };
// MARTES automáticamente adopta el valor 1, MIERCOLES el 2, etc.
```

> [!TIP] Convención de Estilo 
> Por buena práctica de programación, todos los identificadores de constantes de una enumeración se deben escribir completamente en MAYÚSCULAS, reservando las minúsculas para el nombre de las variables.

Dado que en C los caracteres individuales se resuelven internamente como sus equivalentes enteros en la tabla ASCII, es totalmente válido asignarles letras a los elementos de un `enum` (usando llaves `{}`):
```c
enum carreras { INF = 'S', ELE = 'K', IND = 'I' };
```

>[!WARNING] Limitación
>Es fundamental recordar que un `enum` es solo una máscara para el programador. Si intentamos imprimir el valor de una constante de enumeración en la terminal (por ejemplo, haciendo un `printf` de `LUNES`), el programa imprimirá su valor entero asociado (`0`), nunca el nombre textual de la constante.

Tomemos los siguientes casos:
```c
// Caso INCORRECTO
enum dias_habiles {LUNES, MARTES, MIERCOLES
	JUEVES, VIERNES};
enum fin_de_semana {SABADO, DOMINGO};
	
// Caso CORRECTO
enum dias_habiles {LUNES, MARTES, MIERCOLES
	JUEVES, VIERNES};
enum fin_de_semana {SABADO=VIERNES + 1, DOMINGO};
```

>[!INFO] Reglas
>- No conviene tener valores consecutivos con "baches" internos.
>- Si se usa un enumerativo, conviene que la primera constante sea un valor distinto de cero o sea un valor que indique un caso especial de la lista.
>- Las constantes enumerativas deben empezar con mayúscula o bien estar todas en mayúsculas.

El `#define` es otra herramienta que nos permite definir constantes simbólicas, pero con la diferencia de que es resuelta íntegramente por el **preprocesador** antes de la etapa de compilación. Tiene como regla que los identificadores deben estar formados por letras mayúsculas. Se definen:
```c
#define NOMBRE_CONSTANTE valor
```
