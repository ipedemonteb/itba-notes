## Definición

Una **lista simplemente enlazada** es una colección de datos homogéneos y ordenados en la cual el acceso a sus elementos se realiza de manera secuencial iterando de nodo en nodo. A diferencia de los arreglos o vectores, cuyos elementos ocupan posiciones contiguas de memoria y se identifican mediante índices, los nodos de una lista se encuentran dispersos en memoria dinámica y están interconectados a través de punteros.

Estructuralmente, una lista está vacía o se define recursivamente por un primer elemento denominado **cabeza** (_head_), seguido por el resto de la estructura conocido como **cola** (_tail_).
![[Pasted image 20260729214936.png|center|467]]

Operativamente, las listas ofrecen ventajas clave respecto a los arreglos rígidos:
- **Inserción eficiente**: Insertar un elemento requiere únicamente reasignar los punteros del nodo previo y del nuevo nodo, sin necesidad de desplazar el resto de los elementos en memoria. ![[Pasted image 20260729215054.png|center|426]]
- **Eliminación eficiente**: Remover un nodo implica desvincular el puntero del nodo anterior para que apunte directamente al siguiente, liberando la memoria del nodo saliente sin mover bloques de datos. ![[Pasted image 20260729215124.png|center|426]]
- **Búsqueda secuencial**: Dado que no existe acceso aleatorio indexado, la búsqueda de un elemento requiere recorrer la lista linealmente nodo por nodo. Por este motivo, la búsqueda en una lista (incluso ordenada) es menos eficiente en complejidad temporal que la búsqueda binaria en un vector ordenado.

Debido a que cada nodo se reserva dinámicamente durante la ejecución del programa, es fundamental gestionar de manera explícita la memoria asignada. Las operaciones fundamentales que componen el tipo de dato abstracto lista son:
- **Crear lista**: Inicializar la lista (frecuentemente representando la lista vacía mediante un puntero `NULL`).
- **Insertar elemento**: Asignar memoria para un nuevo nodo y enlazarlo en la posición correspondiente.
- **Eliminar elemento**: Unir los nodos adyacentes y liberar la memoria dinámica asignada (`free`).
- **Buscar un elemento**: Recorrer iterativa o recursivamente la estructura verificando las coincidencias.
- **Liberar lista**: Recorrer y destruir secuencialmente cada nodo para evitar pérdidas de memoria (_memory leaks_).

## Declaración de una Lista

Para declarar una lista en C utilizamos estructuras autorreferenciadas. La definición del nodo requiere hacer referencia a la misma estructura mediante un puntero en el campo `tail`:
```c
struct node {
    int head;            // El elemento almacenado
    struct node *tail;   // Puntero al siguiente nodo (la sublista)
};

struct node *myList = NULL; // Lista vacía
```

Al declarar un tipo sin la etiqueta `struct`, el compilador no puede resolver la referencia recursiva antes de conocer el nuevo nombre. Un intento de auto-referenciarse usando únicamente un alias de tipo aún no definido fallará en compilación:
```c
// NO COMPILA:
typedef struct {
    int head;
    TNode *tail; // Error: TNode aún no existe para el compilador
} TNode;
```

Esto ocurre porque dentro del cuerpo de la estructura el identificador `TNode` no se ha terminado de definir. Para declarar correctamente la estructura utilizando alias de tipos (`typedef`), es indispensable conservar la etiqueta del `struct` en la autorreferencia o definir el puntero de manera limpia:
```c
struct node {
    int head;
    struct node *tail;
};

typedef struct node * List;
```

A modo conceptual, se puede visualizar cómo se enlazan manualmente estos nodos en memoria estática o local mediante variables y punteros cruzados. Aunque este esquema ayuda a entender cómo cada nodo apunta a la dirección de memoria del siguiente, en la práctica no se trabaja asignando variables locales directamente, sino reservando dinámicamente cada nodo en el _heap_ a través de punteros de tipo `List`.

## Lista Vacía

Para verificar si una lista está vacía, se evalúa si el puntero que apunta al primer nodo es nulo (`NULL`). Retorna `1` si está vacía y `0` en caso contrario:
```c
int isEmpty(const List list) {
    return list == NULL;
}
```

El parámetro se declara como `const` para garantizar que la función no modifique el puntero ni los datos apuntados dentro de su ámbito. Como `head` es un valor entero (`int`) y no un puntero, nunca podrá tomar el valor `NULL`; por ende, la validación se realiza directamente sobre el puntero a la estructura `List`.

En caso de no utilizar el `typedef List` (que oculta el puntero `struct node *`), la firma y definición de la función equivalente quedan expresadas de la siguiente manera:
```c
int isEmpty(const struct node *list) {
    return list == NULL;
}
```

## Pertenencia

La operación `belongs` determina si un elemento específico se encuentra dentro de la lista, retornando `1` si lo halla o `0` en caso contrario. Su implementación más natural en estructuras autorreferenciadas es de carácter recursivo, donde el caso base ocurre al alcanzar un puntero `NULL` (fin de la lista) o al encontrar la coincidencia.

Para una lista desordenada, la búsqueda evalúa nodo a nodo:
```c
int belongs(const List list, int elem) {
    if (list == NULL)
        return 0;
    if (list->head == elem)
        return 1;
    return belongs(list->tail, elem);
}
```

La lógica recursiva avanza pasando el puntero `list->tail` en cada llamada consecutiva:
- Si la lista es `NULL`, devuelve `0` indicando que el elemento no está presente tras haber recorrido toda la estructura.
- Si el campo `head` coincide con el valor buscado (`elem`), retorna `1` interrumpiendo las llamadas restantes.
- Si no es `NULL` ni coincide, invoca recursivamente a `belongs` sobre el resto de la lista (_tail_).

En el caso de una **lista ordenada** de forma ascendente, es posible optimizar el recorrido deteniendo la búsqueda de manera anticipada en caso de que el valor del nodo actual supere al elemento buscado. Una primera aproximación contempla una condición explícita adicional:
```c
int belongs(const List list, int elem) {
    if (list == NULL)
        return 0;
    if (list->head == elem)
        return 1;
    if (list->head > elem)
        return 0;
        
    return belongs(list->tail, elem);
}
```

Esta estructura se puede simplificar combinando las condiciones de parada en una única expresión mediante el operador lógico `||`:
```c
int belongs(const List list, int elem) {
    if (list == NULL || list->head > elem)
        return 0;
    if (list->head == elem)
        return 1;
        
    return belongs(list->tail, elem);
}
```

>[!TIP] Evaluación de Cortocircuito
>Esta sintaxis unificada es segura gracias a la **evaluación de cortocircuito** (_short-circuit evaluation_ o comportamiento _lazy_) de los operadores lógicos en C. La expresión lógica evalúa primero si `list == NULL`. Si es verdadero, detiene la evaluación inmediatamente y retorna `0`, evitando acceder a `list->head` sobre un puntero nulo y previniendo así un error de desreferenciación (_segmentation fault_).

## Dimensión

La función `size` (o dimensión) calcula la cantidad de nodos presentes en la lista de manera recursiva.

El caso base contempla la lista vacía (`NULL`), cuya longitud es `0`. Para el caso recursivo, la dimensión total corresponde al nodo actual (`1`) más la dimensión de la sublista restante (`size(list->tail)`):
```c
int size(const List list) {
    if (list == NULL)
        return 0;
    return 1 + size(list->tail);
}
```

Aprovechando la función `isEmpty` previamente definida, la implementación puede reescribirse para ganar expresividad:
```c
int size(const List list) {
    if (isEmpty(list))
        return 0;
    return 1 + size(list->tail);
}
```

## Agregado de Elementos en Lista Ordenada

Para agregar un elemento manteniendo el orden ascendente de la lista, la inserción requiere modificar la estructura reservando memoria dinámica con `malloc` e interconectando los punteros correspondientes.

Al insertar un nuevo valor (por ejemplo, `20`), ocurren dos modificaciones en la memoria: se instancia el nuevo nodo asignando su campo `head` y haciendo que su `tail` apunte al resto de la estructura (o `NULL`), y se actualiza el `tail` del nodo anterior (por ejemplo, `10`) para que apunte al nuevo nodo.

Como sabemos, al pasar la lista a una función se pasa una copia del puntero. Por esta razón, la función `add` debe retornar la dirección del primer nodo de la lista modificada para que el llamador pueda actualizar sus referencias.

Una implementación inicial evalúa de forma explícita cada posible escenario de parada o avance:
```c
List add(List list, int elem) {
    if (list == NULL) {
        List aux = malloc(sizeof(struct node));
        aux->head = elem;
        aux->tail = NULL;
        return aux;
    }
    
    if (elem == list->head)
        return list; // El elemento ya existe, no se insertan duplicados
        
    if (elem < list->head) {
        List aux = malloc(sizeof(struct node));
        aux->head = elem;
        aux->tail = list;
        return aux;
    }
    
    list->tail = add(list->tail, elem);
    return list;
}
```

Dado que los casos en los que la lista está vacía (`list == NULL`) y donde el nuevo elemento es menor al actual (`elem < list->head`) comparten la misma lógica de instanciación del nodo, se pueden unificar mediante el operador `||`.

Gracias al comportamiento _lazy_ de la evaluación en C, si `list` es `NULL`, la segunda condición (`elem < list->head`) no se evalúa, evitando un acceso a memoria inválido:
```c
List add(List list, int elem) {
    if (list == NULL || elem < list->head) {
        List aux = malloc(sizeof(struct node));
        aux->head = elem;
        aux->tail = list; // Si list era NULL, aux->tail guardará NULL correctamente
        return aux;
    }
    
    if (elem == list->head)
        return list;
        
    list->tail = add(list->tail, elem);
    return list;
}
```

En los pasos intermedios de la recursión donde no se realiza ninguna inserción, `list->tail` simplemente recibe el mismo puntero que ya tenía y la función retorna `list` intacta hacia el nivel superior del _stack_.

## Eliminar un Elemento de Lista Ordenada

Para eliminar un elemento de una lista ordenada sin perder las referencias de memoria, es clave entender cómo acceder a los nodos subsiguientes (por ejemplo, mediante la navegación `list->tail->tail`).

Cuando "salteamos" el nodo que queremos borrar, debemos guardar previamente una referencia a su sublista para no perder el resto de la estructura y poder liberar de forma segura la memoria asignada a dicho nodo.

La función de eliminación recursiva se implementa de la siguiente manera:
```c
List delete(List list, int elem) {
    if (list == NULL || list->head > elem)
        return list;

    if (list->head == elem) {
        List aux = list->tail;
        free(list);
        return aux;
    }

    list->tail = delete(list->tail, elem);
    return list;
}
```

Al encontrar el elemento buscado, guardamos la dirección del siguiente nodo (`list->tail`) en una variable auxiliar `aux`. Luego liberamos la memoria del nodo actual mediante `free(list)` y retornamos `aux`. De esta manera, el nodo anterior en la pila de llamadas reasigna su puntero `tail` directamente al nuevo frente de la sublista, salteando efectivamente el elemento eliminado.

En caso de no encontrar la coincidencia en el nodo actual, realizamos el paso recursivo aplicando `delete` sobre la sublista (`list->tail`), manteniendo el mismo esquema que utilizamos para agregar elementos.

## Obtención de Head y Tail

La función `head` devuelve el primer elemento (el valor guardado en el primer nodo) de la lista. Dado que acceder al valor de una lista vacía es un error de ejecución, se debe validar que la lista contenga datos antes de desreferenciar el puntero.

Una primera opción consiste en abortar la ejecución del programa mediante `exit(1)` si la condición falla.
```c
int head(const List list) {
    if (isEmpty(list))
        exit(1);
    return list->head;
}
```

Una alternativa más limpia y estándar en C consiste en utilizar macros de aserción del encabezado `<assert.h>` mediante `assert`:
```c
int head(const List list) {
    assert(!isEmpty(list));
    return list->head;
}
```

En este segundo caso, `assert` evalúa que la condición dada sea verdadera (que la lista **no** esté vacía). Si la aserción se cumple, la función retorna `list->head`; de lo contrario, el programa finaliza indicando el fallo en tiempo de ejecución.

La función `tail` devuelve el puntero a la sublista restante (el resto de la lista excluyendo el nodo actual). Al igual que sucede con `head`, intentar obtener la cola de una lista vacía es un error de ejecución, por lo que es necesario validar previamente que la lista no esté vacía.

Utilizando la macro de aserción `assert` de `<assert.h>`, la función se implementa del siguiente modo:
```c
List tail(const List list) {
    assert(!isEmpty(list));
    return list->tail;
}
```

Si la lista contiene al menos un elemento, la aserción se evalúa como verdadera y la función retorna `list->tail`, devolviendo el puntero al siguiente nodo o `NULL` si el nodo actual era el único en la lista.

## Liberación de Lista

Para liberar completamente la memoria asignada a una lista en C, podríamos optar por una solución iterativa. Sin embargo, resulta muy ilustrativo implementarla de manera recursiva.
```c
void freeList(List list) {
    if (list == NULL)
        return;
    freeList(list->tail);
    free(list);
}
```

En la primera verificación, evaluamos si la lista es `NULL`; este constituye nuestro caso base, donde no se realiza ninguna acción y la función retorna. En el paso recursivo, invocamos `freeList` sobre la sublista (`list->tail`). Las llamadas se van apilando en la memoria hasta alcanzar el `NULL` final, momento en el cual la función comienza a desapilarse y realiza el `free(list)` de cada nodo de atrás hacia adelante, garantizando que nunca accedemos a la propiedad `tail` de un puntero ya liberado.

Si intentamos alterar la secuencia para liberar la cabeza antes de realizar la llamada recursiva, nos encontramos con un problema grave de acceso a memoria no válida (_use-after-free_):
```c
// Versión incorrecta / con comportamiento indefinido
void freeList(List list) {
    if (list == NULL)
        return;
    List aux = list->tail;
    freeList(list); // Llamada recursiva sobre el nodo actual
    free(aux);
}
```

Al llamar a `freeList(list)` pasándole el mismo puntero en lugar de avanzar, la función entra en un bucle recursivo infinito sobre el mismo nodo, o bien intenta acceder a un bloque de memoria que ya fue liberado en una llamada previa, produciendo comportamiento indefinido. Por esta razón, en la liberación recursiva de estructuras vinculadas, la llamada recursiva a la cola debe preceder siempre a la liberación del nodo corriente.

## Pasar una Lista a Array

Para convertir una lista en un vector o arreglo dinámico en C, se suele emplear un enfoque iterativo. Entre recorrer la lista dos veces (una para calcular la dimensión y otra para copiar los elementos) o hacer llamadas sucesivas a `realloc` elemento por elemento, **es preferible recorrerla dos veces**. La primera pasada sirve para averiguar el tamaño mediante `size(list)` y reservar en memoria la cantidad exacta de bytes necesarios, mientras que la segunda llena el arreglo.

Una implementación directa usando un bucle `while` se plantea así:
```c
int * toArray(const List list) {
    int * resp = malloc(size(list) * sizeof(list->head));
    List aux = list;
    int index = 0;
    while (aux != NULL) {
        resp[index++] = aux->head;
        aux = aux->tail;
    }
    return resp;
}
```

Como el parámetro `list` se pasa por valor, no es obligatorio declarar una variable auxiliar `aux`; se puede iterar directamente reasignando la variable local `list`:
```c
int * toArray(const List list) {
    int * resp = malloc(size(list) * sizeof(list->head));
    int index = 0;
    while (list != NULL) {
        resp[index++] = list->head;
        list = list->tail;
    }
    return resp;
}
```

>[!WARNING] Cuidado
>Si se decide utilizar un bucle `for`, hay que evitar evaluar `size(list)` en la condición del ciclo (`for(int i = 0; i < size(list); i++)`), ya que esto recalcularía el tamaño completo de la lista en cada iteración, transformando un algoritmo $O(N)$ en uno $O(N^2)$.

La forma eficiente de estructurar el bucle `for` guarda primero la dimensión en una variable:
```c
int * toArray(const List list) {
    int dim = size(list);
    int * resp = malloc(dim * sizeof(list->head));
    int index = 0;
    for (int i = 0; i < dim; i++, list = list->tail) {
        resp[index++] = list->head;
    }
    return resp;
}
```

## Recursividad de Cola y de Pila

La distinción entre recursividad de pila (Head/Non-Tail Recursion) y recursividad de cola (Tail Recursion) radica en el momento en que se realizan las operaciones pendientes dentro del marco de ejecución (_stack frame_).

La **recursividad de pila** ocurre cuando la llamada recursiva no es la última operación que ejecuta la función. Tras retornar de la llamada recursiva, la función todavía debe realizar algún trabajo adicional (por ejemplo, una multiplicación). Esto exige que el compilador mantenga el estado de cada marco en la pila de llamadas (_call stack_) hasta completar el desapilado.

En el ejemplo del factorial:
```c
int factorial(int n) {
    if (n <= 1)
        return 1;
    
    int aux = factorial(n - 1);
    return n * aux;
}
```

La operación `n * aux` queda pendiente en cada nivel de la pila hasta que la llamada `factorial(n - 1)` devuelve su resultado.

La **recursividad de cola** ocurre cuando la llamada recursiva es estrictamente la última acción que realiza la función, de modo que el valor retornado por la llamada interna es devuelto directamente sin realizar operaciones posteriores sobre él.

Para transformar la función factorial en una versión con recursividad de cola pura, se suele pasar un acumulador a través de los parámetros (a menudo auxiliado por una función wrapper o un parámetro por puntero):
```c
// Versión con parámetro acumulador (Tail Recursive)
int factorialTail(int n, int acc) {
    if (n <= 1)
        return acc;
    
    return factorialTail(n - 1, n * acc); // La llamada recursiva es la última instrucción
}
```

Cualquier problema resoluble mediante recursividad de cola puede expresarse también utilizando recursividad de pila. La principal ventaja técnica de la recursividad de cola es que permite a los compiladores aplicar la optimización de llamada final (_Tail Call Optimization_ o TCO), reutilizando el mismo marco de pila y convirtiendo la recursión en un bucle a nivel de lenguaje ensamblador, lo que reduce el consumo de memoria de $O(N)$ a $O(1)$.
